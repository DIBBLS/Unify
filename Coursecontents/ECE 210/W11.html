Week 11 of 11 Diodes & Rectification — Half-Wave, Full-Wave & Ripple

Every device running from a wall socket needs rectification — AC to DC. Diodes are the one-way valves that make it possible. Half-wave uses one half of the AC cycle. Full-wave bridge uses both. Ripple factor measures how rough the DC output is.

Topic 11.1
Diodes, Rectification & Ripple Factor

Diode: allows current in one direction only. Forward biased (anode positive): conducts with ~0.7V drop. Reverse biased: blocks. Symbol: arrow points in direction of conventional current.

Half-wave rectifier: one diode. Only positive half-cycles pass. Vdc = Vm/π = 0.318Vm. Vrms = Vm/2. High ripple, inefficient — half the AC cycle wasted.

Full-wave bridge: four diodes. Both half-cycles used. Positive half: D₁+D₄ conduct. Negative half: D₂+D₃ conduct. Load current always same direction. Vdc = 2Vm/π = 0.637Vm. Vrms = Vm/√2. Lower ripple, practical. Output frequency = 2f (100Hz).

Zener diode: operates in reverse breakdown at constant Vz. Used for voltage regulation — maintains stable output despite load or supply changes. Always use with series resistor to limit current.

Rectifier equations and ripple factor
Half-wave: Vdc=0.318Vm, Vrms=0.5Vm, r≈1.21
Full-wave: Vdc=0.637Vm, Vrms=0.707Vm, r≈0.48
Vac = √(Vrms² − Vdc²)
r = Vac/Vdc = √[(Vrms/Vdc)² − 1]
Ripple factor derivation: Vrms² = Vdc² + Vac² → Vac = √(Vrms²−Vdc²) → r = Vac/Vdc = √[(Vrms/Vdc)²−1]
Lower r = smoother DC · Full-wave r=0.48 much better than half-wave r=1.21
Worked Example — Full-Wave Ripple Factor

Full-wave rectifier, Vm=100V. Find Vdc, Vrms, Vac, r.

Vdc = 2×100/π = 63.7V · Vrms = 100/√2 = 70.7V

Vac = √(70.7²−63.7²) = √940.8 = 30.67V

r = 30.67/63.7 = 0.48

Vdc=63.7V · Vrms=70.7V · Vac=30.67V · r=0.48
Common mistake
Using input mains Vrms (e.g. 230V) in ripple formula instead of the output Vrms (= Vm/√2 for full-wave). These are completely different values. The ripple formula uses the RMS of the rectified output waveform.
