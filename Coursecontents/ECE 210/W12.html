Section A
Complete Formula Sheet — Weeks 1–11
Weeks 1–2 · Magnetic Circuits
B = φ/A    (flux density, T)
H = NI/L    (magnetising force, A/m)
B = μ₀μᵣH    (B-H relationship)
ℛ = L/(μ₀μᵣA)    (reluctance, A·t/Wb)
F = φℛ = NI    (Ohm's Law for magnetics)
Air gap: H_gap = B/μ₀ = 7.96×10⁵ × B  ·  μ₀ = 4π×10⁻⁷ H/m
Weeks 3–6 · DC Machines
E = (φZNP) / (60A)    (EMF equation)
T = (φZI_a × P) / (2πA)    (torque)
Motor: V = E + I_aR_a    Generator: V = E − I_aR_a
N ∝ (V − I_aR_a) / φ    (speed equation)
Z = armature conductors · P = poles · A = parallel paths · N = speed (rpm)
Lap winding: A = P  ·  Wave winding: A = 2
Weeks 7–8 · Transformers
k = N₁/N₂ = V₁/V₂ = I₂/I₁    (turns ratio)
Z₂' = k²Z₂    (refer secondary → primary)
Z₁' = Z₁/k²    (refer primary → secondary)
η = V₂I₂cosφ / (V₂I₂cosφ + W_i + I₂²R_eq)
Max η when W_i = I²R_eq    x_maxη = √(W_i / W_cu(FL))
OC test → iron loss W_i (LV side excited, HV open)
SC test → copper loss W_cu (HV side excited, LV shorted)
Week 9 · AC Circuits
V_rms = V_m/√2 = 0.707 V_m     V_avg = 0.637 V_m
X_L = 2πfL    X_C = 1/(2πfC)    Z = √(R²+X²)
cosφ = R/Z    P = VIcosφ    Q = VIsinφ    S = VI
Phasors: V = √(V_R²+V_L²) — do NOT add arithmetically
Week 10 · Induction Motors
Ns = 120f/P    s = (Ns−N)/Ns    N = Ns(1−s)
f_r = s×f    Rotor copper loss = s × P_ag
P_mech = (1−s) × P_ag    Rotor η = N/Ns
P = total poles · f = 50Hz · s = 0 at synchronous, s = 1 at standstill
Week 11 · Rectifiers
Half-wave: V_dc = 0.318 V_m    V_rms = 0.5 V_m    r ≈ 1.21
Full-wave: V_dc = 0.637 V_m    V_rms = 0.707 V_m    r ≈ 0.48
r = √[(V_rms/V_dc)² − 1]    (ripple factor)
Full-wave ripple frequency = 2f = 100Hz  ·  Lower r = smoother DC
Section B
Top Mistakes That Lose Exam Marks
Magnetic circuits
① Confusing φ (Wb) with B (T). ② Using μᵣ alone instead of μ₀μᵣ in reluctance. ③ Using B-H curve for air — always use H_gap = B/μ₀. ④ P in Ns=120f/P is total poles, not pole pairs.
DC machines
① Back EMF sign: motor V = E + I_aR_a (back EMF opposes supply). Generator V = E − I_aR_a. ② Parallel paths A: lap → A=P, wave → A=2.
Transformers
① LV→HV: multiply by k². HV→LV: divide by k². Never multiply in both directions. ② OC test on LV (iron loss). SC test on HV (copper loss). ③ Transformer never works on DC — Faraday's Law: dφ/dt=0 for DC → zero EMF.
AC circuits
① Power calculations always use V_rms, never V_m. ② V_R + V_L ≠ V_total. They are 90° apart — use V = √(V_R²+V_L²).
Induction motors
① Rotor never reaches Ns during motoring. ② Rotor copper loss = s×P_ag (not (1−s)×P_ag). ③ WRIM is not more efficient than SCIM during normal running.
Rectifiers
① Output is pulsating DC, not smooth — capacitor filter needed. ② Ripple factor uses output V_rms, not mains V_rms. ③ Full-wave ripple frequency = 100Hz, not 50Hz.
Section C
High-Frequency Past Question Patterns
These question types appear almost every year
MagneticCore with air gap: find current for a given flux. Method: B=φ/A → H from curve → H_gap=B/μ₀ → NI=ΣHL → I=NI/N
MagneticSketch hysteresis loop. Label Bₘ, Bᵣ, Hc. Distinguish eddy current loss from hysteresis loss — cause and remedy for each.
TransformerGiven kVA rating and winding resistances, find equivalent resistance referred to each side. Verify: R_eq(HV)/R_eq(LV) = k².
TransformerState condition for maximum efficiency. Find load fraction at which it occurs given W_i and W_cu(FL).
TransformerWhy does a transformer not work on DC? Explain using Faraday's Law (dφ/dt=0 → e=0).
ACRL series circuit: find Z, I, power factor, V_R and V_L. Verify: √(V_R²+V_L²) = V_supply.
Induction3-phase IM: find synchronous speed, rotor speed at given slip, rotor frequency at given rpm.
InductionWhy can an induction motor never reach synchronous speed? Define slip and state its extreme values.
RectifierDerive ripple factor r = √[(V_rms/V_dc)²−1]. Calculate r for full-wave rectifier with given V_m.
RectifierDraw full-wave bridge rectifier. Trace current through each half-cycle. Identify which diodes conduct.
Exam strategy
1. Read all questions first — do what you know cold first, then return to harder ones.
2. Show every step. Partial marks are awarded for correct method even if the final answer is wrong.
3. State your formula before substituting numbers — examiners reward structured working.
4. For definitions: be precise and concise. One correct sentence beats a vague paragraph.
5. Always write units on every answer. A number without a unit is incomplete.
