Week 6 of 12 Governors — Types & Simple Governor Analysis

A governor is a speed regulator. When an engine goes too fast, the governor cuts fuel. When it's too slow, it adds more. This week you learn the types of governors and how to analyse the simplest kind using the height formula h = g/ω².

Topic 6.1
What is a Governor? Types

A governor is the automatic speed controller of an engine. Without it, if load suddenly drops (say a machine disconnects), the engine would race to dangerous speeds. The governor senses the speed change and physically adjusts the fuel supply to bring speed back to normal.

Exam-ready definition (from notes)
A governor is a device used to regulate the fluctuation of speed in an engine. It maintains the constant mid speed.
Types of governors
1. Centrifugal governors — use centrifugal force of rotating balls
a) Pendulum type
b) Loaded type → Dead weight type / Spring load type
2. Inertial governors — work on principle of inertia force
Key terms: h = height of governor · Fc = centrifugal force = mω²r · r = radius of rotation · W = weight of ball · T = tension in arms · Sleeve lift = vertical distance travelled by sleeve due to change in equilibrium speed
Simple centrifugal governor — force diagram
Simple governor height formula (derived from moment equilibrium)
Taking moments about O: Wlr − Fc·h = 0
∴ Fc·h = W·l·r
∴ h = g / ω²
where ω = 2πN/60 (in radians per second)
∴ h = g / (2πN/60)²
h = height of governor (m) · g = 9.81 m/s² · ω = angular speed (rad/s) · N = speed in rpm
Real-world example
Think of a spinning coin on a table. The faster it spins, the more it tilts outward (centrifugal effect). A governor's balls do the same — spin faster → balls fly outward → sleeve lifts → fuel valve closes → engine slows. It's a beautiful automatic feedback loop.
Common mistake
Plugging N (in rpm) directly into h = g/ω² without converting to rad/s. ω = 2πN/60. Always convert first. If N = 100 rpm → ω = 10.47 rad/s, NOT 100.
