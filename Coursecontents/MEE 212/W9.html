Week 9 of 12 Epicyclic Gear System — Tabular Method

The epicyclic (planetary) gear system is the most complex gear arrangement. One or more gears orbit around another gear. The tabular method is the cleanest way to solve these problems — and it always follows the same 3 steps.

Exam focus
  1. Use the tabular method to find speed of any gear in an epicyclic system. Common exam Q
  2. Set up the table with 3 steps: arm fixed, arm rotates x, add y.
  3. Apply conditions (fixed gear = 0 speed) to find x and y, then solve.
Topic 9.1
The Tabular Method — 3 Steps

Here's the deal with epicyclic gears: the arm (the thing that holds the planet gears) can also rotate. This makes it confusing. The tabular method fixes that by breaking everything into 3 simple steps that always work.

3-step tabular method
Step 1: Fix the arm. Give gear A exactly +1 revolution. Fill in all gear speeds using gear ratio rules (−Z_A/Z_C for meshing gears).
Step 2: Now fix the arm. Give gear A exactly +x revolutions. Multiply entire Step 1 row by x.
Step 3: Add y to every element in every column. This accounts for the arm's actual rotation.
x and y are found by applying conditions (e.g. arm speed = y, fixed gear speed = 0 → set the gear's column = 0 and solve)
Speed of gear B in compound epicyclic
N_B = y + x[Z_A/Z_C × Z_D/Z_B]
Z_A = teeth on gear A · Z_C, Z_D = teeth on intermediate gears · Z_B = teeth on gear B · y = arm speed · x = relative rotation
Worked Example — Epicyclic gear (from notes 07-01-2025)

Gears A, B & C in epicyclic system. A has 72 internal teeth. C has 82 external teeth. B meshes with both A & C. Arm EF carries C and rotates anticlockwise at 18 rpm. A is fixed. Find speed of B and C.

Setup table: columns → Arm EF | Gear A | Gear B | Gear C
Step 1 (arm fixed, A rotates +1): Arm=0, A=+1, B=−Z_A/Z_C × Z_C/Z_B, C=−Z_A/Z_C
Step 2 (multiply by x): Arm=0, A=+x, B=x×(−Z_A/Z_B), C=x×(−Z_A/Z_C)
Step 3 (add y): Arm=y, A=x+y, B=y+x(−Z_A/Z_B), C=y+x(−Z_A/Z_C)
Condition 1 — A is fixed: x + y = 0 → x = −y
Condition 2 — Arm speed = 18 rpm (anticlockwise = −18): y = −18
∴ x = 18
Speed of C: y + x(−Z_A/Z_C) = −18 + 18×(−72/82) = −18 − 15.8 = −27.58 rpm ≈ 27.6 rpm CW
Speed of A (check): x + y = 18 + (−18) = 0 ✓ (A is fixed)
Worked Example 2 — Compound epicyclic (from notes)

Z_C=28, Z_D=26, Z_E=18, Z_F=28. N_EF = 18 rpm (arm). N_G = 100 rpm CW. Find N_A, N_B.

y = 18 rpm (arm speed)
For gear C: y − x(Z_C/Z_A) = 0 → 18 = x(82/72) → x = 18×72/82 = 40.5 rpm
Speed of C: x + y = 40.5 + 18 = 58.5 rpm
N_B: = y − x(Z_C/Z_B) = 18 − [40.5×82/20] = 18 − 166 = −48.8 rpm (CW)
Common mistake
Forgetting to ADD y in Step 3 — students often just multiply by x and stop. The y term is the arm's absolute rotation, and without it, all your answers are relative, not absolute. Always do all 3 steps.
