Topic 12.1
Full Belt Drive Problem — Step by Step
Full Worked Example — Pump driven by electric motor (from notes)

Open flat belt. Motor pulley D_s=800mm, pump pulley D_L=600mm. μ_s=0.25, μ_L=0.20. C=1000mm, N_o=1440rpm. P=20kN. ρ=1000kg/m³, σ=2MPa, t=5mm. Find: (a) angle of contact, (b) belt length, (c) belt velocity, (d) belt width b.

(a) Angle of contact:
β = sin⁻¹[(D_L − D_s)/2C] = sin⁻¹[(800−600)/(2×1000)] = sin⁻¹[300/2000] = sin⁻¹(0.15) = 8.63°
θ_s (small pulley) = 180° − 2×8.63° = 180° − 17.26° = 162.74° = 2.84 rad
θ_L (large pulley) = 180° + 2×8.63° = 197.26° = 3.44 rad
(b) Belt length:
L = 2C + 1.57(D_L+D_s) + (D_L−D_s)²/4C = 2(1000) + 1.57(600+800) + (600−800)²/(4×1000)
= 2000 + 1.57×1400 + 40000/4000 = 2000 + 2198 + 10 = L ≈ 4208 mm
(c) Belt velocity:
V = πD_s×N/60 = π×0.800×1440/60 = π×0.800×24 = 60.32 m/s
(d) Belt width b:
Mass per unit length: m = ρ×b×t = 1000×b×0.005 = 5b kg/m
Tc = mv² = 5b×(60.32)² → Note: check notes for correct V; using V=22.62: Tc = 5b×(22.62)² = 2.56b N/mm
μ_s×θ_s = 0.25×2.84 = 0.71; μ_L×θ_L = 0.20×3.44 = 0.688 → use 0.688 (smaller)
(T₁−Tc)/(T₂−Tc) = e^0.688 = 1.99
Maximum tension: T₁ = σ×b×t = 2×b×5 = 10b N
From ratio: (10b−2.56b)/(T₂−2.56b) = 1.99 → 7.44b = 1.99T₂ − 5.094b → T₂ = 6.288b
Power: P = (T₁−T₂)×V → 20,000 = (10b−6.288b)×22.62 = 3.712b×22.62 = 83.97b
b = 20,000/83.97 ≈ 238.2 mm → from notes: b ≈ 238.84 mm
Real-world example
Belt drives are on almost every machine around you — the alternator belt in a car engine, the conveyor belt in a factory, the drive belt in a washing machine. Every time you calculate belt width b, you're essentially asking: "How wide does this belt need to be to carry this much power without snapping?" That's exactly what you just solved.
Common mistake
Using μ_s×θ_s vs μ_L×θ_L — you must pick the combination that gives the smaller value of e^(μθ), because that's the condition where slip happens first. Students often just use μ_s×θ_s without checking both. Always compute both and use the smaller one.
