Question 1
AI Model for Predicting Concrete Strength in Civil Engineering
Development of an ANN-based Regression Model

Question: A civil engineering laboratory wants to develop an AI system capable of predicting the compressive strength of concrete based on the quantities of its constituent materials. The dataset contains:

  • Cement content
  • Water content
  • Sand quantity
  • Gravel quantity
  • Curing age

Describe how an AI model can be developed for this problem and determine the suitable learning approach.

Step 1

Problem Identification

The aim is to predict the numerical value of concrete compressive strength.

Problem Type: Regression — because the output is a continuous numerical value (compressive strength), not a category.
Step 2

Data Acquisition

Experimental data are obtained from laboratory concrete tests conducted over several months. Each record contains:

  • Input variables: Cement, Water, Sand, Gravel, Curing age
  • Output variable: Compressive strength
Step 3

Data Preparation

Data preprocessing involves:

  • Handling missing values
  • Removing outliers
  • Normalizing data values
  • Splitting the dataset into:
    • Training set
    • Validation set
    • Testing set
Step 4

Selection of AI Technique

Suitable algorithms include:

  • Linear Regression
  • Decision Tree Regression
  • Artificial Neural Networks
Best Choice: Artificial Neural Network (ANN) — highly suitable because concrete strength depends on complex nonlinear relationships among the input materials. ANN can learn these patterns from data.
Step 5

Model Architecture

Example ANN structure:

  • Input layer — 5 nodes: Cement, Water, Sand, Gravel, Curing age
  • Hidden layers — Learn relationships among variables
  • Output layer — Predicted compressive strength (single continuous value)
Step 8

Deployment

The trained model can be integrated into civil engineering software to help engineers estimate concrete strength before actual production, thereby saving time and cost.

What is the difference between a regression problem and a classification problem? Which type is the concrete strength prediction?
A regression problem outputs a continuous numerical value (e.g. 45.2 MPa). A classification problem assigns input to a discrete category (e.g. Strong / Weak). Concrete strength prediction is a regression problem because the output is a continuous compressive strength value.

Question 2
AI Model for Traffic Sign Recognition in Autonomous Vehicles
Development of a CNN-based Computer Vision Classification Model

Question: An Electronic and Computer Engineering research team intends to develop an AI system capable of recognizing traffic signs for use in autonomous vehicles. The available dataset consists of thousands of labeled images containing:

  • Stop signs
  • Speed limit signs
  • Warning signs
  • Pedestrian crossing signs
  • Traffic lights

Explain the steps involved in developing the AI model and identify the most suitable AI technique for the system.

Step 1

Problem Definition

The objective is to develop an AI model that can identify and classify traffic signs from images in real time.

Problem Type: Computer Vision Classification — the model categorizes images into predefined classes (stop sign, speed limit sign, etc.).
Step 2

Data Collection

The dataset is obtained from:

  • Cameras mounted on vehicles
  • Public traffic sign databases
  • Road surveillance systems

Each image must be labeled correctly according to the traffic sign category.

Step 3

Data Preprocessing

Image preprocessing operations include:

  • Resizing images to uniform dimensions
  • Noise reduction
  • Image normalization
  • Data augmentation:
    • Rotation
    • Flipping
    • Brightness adjustment
Note: Data augmentation improves model robustness by artificially increasing the variety of training images.
Step 4

Selection of AI Technique

Best Choice: Convolutional Neural Network (CNN) — CNNs are highly effective for image recognition because they automatically extract important visual features such as edges, shapes, and patterns.
Step 5

Model Architecture

Typical CNN architecture includes:

  • Input Layer — receives the image pixel data
  • Convolutional Layers — extract features (edges, shapes)
  • Pooling Layers — reduce spatial dimensions
  • Fully Connected Layers — learn high-level patterns
  • Output Layer — class probabilities

Example output classes: Stop sign · Speed limit sign · Traffic light · Warning sign · Pedestrian crossing

Comparison
Compare ANN (Question 1) and CNN (Question 2). What is the key advantage of CNN for image-based tasks?
Both are neural networks, but CNNs have specialised layers (Convolutional and Pooling) that automatically extract visual features such as edges, shapes, and patterns from images. An ANN treats each pixel as an independent input and doesn't capture spatial structure. CNNs are therefore far more effective for image classification tasks.

Question 3
AI-Based Network Intrusion Detection System
Development of a Random Forest Classifier for Cybersecurity

Question: A Computer Engineering firm plans to develop an AI-based Intrusion Detection System (IDS) capable of detecting cyberattacks in a computer network. The dataset contains:

  • Source IP address
  • Destination IP address
  • Packet size
  • Protocol type
  • Login attempts
  • Historical attack records

Describe the procedure for developing the AI model and identify the appropriate machine learning method.

Step 1

Problem Identification

The aim is to detect malicious network activities and classify them as:

  • Normal traffic
  • Suspicious traffic
  • Attack traffic
Problem Type: Classification — the model assigns each network activity to one of the defined categories.
Step 2

Data Collection

Data are collected from:

  • Routers
  • Firewalls
  • Servers
  • Network monitoring tools

Historical cyberattack data are also included.

Step 3

Data Preprocessing

Preprocessing activities include:

  • Removal of duplicate records
  • Handling missing data
  • Feature encoding
  • Data normalization

The dataset is divided into Training dataset and Testing dataset.

Step 4

Selection of AI Algorithm

Suitable algorithms include:

  • Random Forest
  • Support Vector Machine (SVM)
  • Deep Neural Network (DNN)
Best Choice: Random Forest Classifier — appropriate because it handles large network datasets efficiently and provides high detection accuracy. It also resists overfitting by averaging multiple decision trees.
Step 5

Feature Extraction

Important features extracted include:

  • Frequency of login failures
  • Unusual packet transmission rate
  • Unknown IP connections
  • Abnormal traffic patterns
Step 6

Model Training

The AI model is trained using supervised learning.

  • Inputs: Packet information, Protocol details, Connection behavior
  • Outputs: Normal · Intrusion
Step 7

Model Evaluation

Performance is measured using:

  • Accuracy
  • Precision
  • Recall
  • False Positive Rate (FPR)
Step 8

Deployment

The AI-based IDS is integrated into the network infrastructure to monitor traffic continuously and alert administrators whenever suspicious activities are detected.
