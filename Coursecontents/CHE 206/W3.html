Topic 3.1
Intensive vs Extensive Properties

A thermodynamic property is any observable characteristic of a system. Properties come in two types and knowing the difference is an easy exam mark.

Extensive properties depend on how much matter you have. Double the mass, double the property value. Examples: total volume V, total internal energy U, total enthalpy H, total entropy S.

Intensive properties don't change with the amount of matter. Split a system in half and each half has the same value. Examples: temperature T, pressure P, density ρ, specific volume v (= V/m).

The trick: divide any extensive property by mass and it becomes intensive. That's why we use lowercase letters for specific (per-kg) quantities: v = V/m, u = U/m, h = H/m.

Exam-ready definitions
An extensive property is one which depends on the magnitude (mass) of the system. If a system is divided into parts, the extensive property of the whole equals the sum of that property for each part. Examples: volume, internal energy, enthalpy, entropy.

An intensive property is one which is independent of the magnitude or mass of matter. The value remains the same regardless of how the system is subdivided. Examples: temperature, pressure, density, specific volume.

Topic 3.2
First Law Applied — The Rigid Tank Problem

The First Law says ΔU = Q − W. For a closed system with no moving parts (rigid tank), volume is constant so there's no boundary work. W = 0. If it's also insulated (adiabatic), Q = 0 too. So any energy input — like an electrical resistor — goes entirely into raising internal energy.

First Law for a closed system
ΔU = Q − W
Rigid tank (constant volume): W = 0, so ΔU = Q
Insulated rigid tank: Q = 0 and W = 0, so ΔU = 0 unless electrical work is done
For an ideal gas: ΔU = nCᵥΔT
Worked example — CHE 206 past question (rigid tank)
Given

V = 300 litres = 0.3 m³, T₁ = 450 K, P₁ = 2 bar, T₂ = 550 K, nitrogen (ideal gas), Cᵥ = 5R/2, R = 8.3144 J/g·mol·K

Step 1 — Find moles of nitrogen

PV = nRT → n = P₁V/(RT₁) = (2×10⁵ × 0.3)/(8.3144 × 450) = 16.03 mol

Step 2 — Work done (rigid tank = no boundary work)

W_boundary = 0. W_electrical = ΔU = nCᵥΔT = 16.03 × (5/2 × 8.3144) × 100 = 33,285 J ≈ 33.3 kJ

Step 3 — Final pressure

P₁/T₁ = P₂/T₂ → P₂ = 2 × 550/450 = 2.44 bar

Common mistake
Forgetting that an electrical resistor does work ON the gas. The sign convention in CHE 206 is ΔE = Q − W, so electrical work input appears as a negative W term, giving positive ΔU. Also watch: some textbooks write ΔE = Q + W — both conventions exist, you must be consistent.
