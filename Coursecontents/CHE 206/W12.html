Topic 12.1
How to Use Steam Tables — Step by Step

Steam tables give you pre-calculated thermodynamic properties of water at various states. The key skill is knowing which table to open and how to identify the state of your steam before you look anything up. If you look up the wrong table, you'll get a wrong answer even with perfect arithmetic.

Step 1 — Identify the phase (always do this first)
How to identify the state of your steam

Given P, find Tsat from saturated table. Then:
— If T = Tsat → saturated (on the boundary)
— If T < Tsat → subcooled liquid
— If T > Tsat → superheated → use superheated table

Given P and u (or h): Look up uf and ug at that pressure.
— If u < uf → subcooled liquid
— If uf ≤ u ≤ ug → wet vapour (two-phase), find x
— If u > ug → superheated → use superheated table

Step 2 — Linear interpolation formula
y = y₁ + (x − x₁)/(x₂ − x₁) × (y₂ − y₁)
Use when your exact value (x) is not in the table — interpolate between the two nearest tabulated values
Worked example 1 — finding x from enthalpy (2017/18 past question)
Given: P = 2 bar, h = 2340 kJ/kg. Find dryness fraction x.
Step 1 — Check state

At P = 2 bar: hf = 505 kJ/kg, hg = 2707 kJ/kg. Since hf < h < hg → wet vapour ✓

Step 2 — Find x

hfg = 2707 − 505 = 2202 kJ/kg
x = (h − hf)/hfg = (2340 − 505)/2202 = 1835/2202 = 0.833

Worked example 2 — superheated steam (2022/23)
Given: P = 1.0 MPa = 10 bar, T = 250°C. Find specific enthalpy h.
Step 1 — Identify state

At P = 10 bar: Tsat = 179.9°C. Since T = 250°C > Tsat → superheated steam ✓

Step 2 — Read superheated table

At P = 10 bar and T = 250°C: h = 2943 kJ/kg

Worked example 3 — interpolation (CHE 206 past question)
Find hf at P = 20 kPa, given table values at 10 kPa and 30 kPa
From table: hf(10 kPa) = 191.8 kJ/kg, hf(30 kPa) = 289.2 kJ/kg
Apply interpolation

hf(20 kPa) = 191.8 + (20−10)/(30−10) × (289.2−191.8) = 191.8 + 48.7 = 240.5 kJ/kg

Analogy
A steam table is like a bus timetable. You look up the route (pressure) and the time (temperature or property). If your exact stop isn't listed, you interpolate. The key is knowing which timetable book to open: saturated or superheated. Open the wrong one and you'll miss your bus.
Common mistakes
1. Not checking which region the steam is in before looking up the table. Always check T vs Tsat first.
2. Interpolating in the wrong direction. Make sure x₁ < x < x₂.
3. Using bar and MPa inconsistently. 1 bar = 100 kPa = 0.1 MPa. Convert before looking up.
Exam-ready — interpolation formula
When a required property value lies between two tabulated values, linear interpolation is used: y = y₁ + [(x − x₁)/(x₂ − x₁)] × (y₂ − y₁), where (x₁, y₁) and (x₂, y₂) are the two tabulated data points bracketing the required value x.
