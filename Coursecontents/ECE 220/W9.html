Week 9 of 12 Dictionaries & Sets

Dictionaries store data as key-value pairs — the most powerful and flexible Python data structure. Unlike lists (index-based), dictionaries let you look up values by a meaningful name. Sets store unique items with no duplicates — useful for membership testing and set operations.

Topic 9.1
Dictionaries — Key-Value Pairs

A dictionary is a collection of key-value pairs enclosed in {}. Each key maps to a value. Keys must be unique; values can be anything.

Analogy
A dictionary is like a real dictionary — you look up a word (key) to find its meaning (value). Instead of searching by position (like a list), you search by name.
# Creating a dictionary student = { "name": "Amaka", "matric": "150201001", "level": 200, "gpa": 3.75 } # Accessing values print(student["name"]) # Amaka print(student["gpa"]) # 3.75 # Safe access with .get() (no error if key missing) print(student.get("age", "Not found")) # Not found # Adding and modifying student["age"] = 20 # add new key student["gpa"] = 3.90 # update existing # Looping through dictionary for key, value in student.items(): print(f"{key}: {value}")
Key dictionary methods
.keys() — all keys: dict(["name","level","gpa"])
.values() — all values
.items() — all key-value pairs as tuples
.get(key, default) — safe access, no KeyError
key in dict — check if key exists (returns True/False)
del dict[key] — remove a key-value pair
Common mistake
Using dict["missing_key"] raises a KeyError if the key doesn't exist. Always use dict.get("key", default) when you're unsure if a key is present.
Topic 9.2
Sets — Unique Collections

A set stores unique, unordered items. Duplicates are automatically removed. Useful for membership testing and mathematical set operations.

# Creating sets A = {1, 2, 3, 4} B = {3, 4, 5, 6} print(A | B) # Union: {1, 2, 3, 4, 5, 6} print(A & B) # Intersection: {3, 4} print(A - B) # Difference: {1, 2} print(A ^ B) # Symmetric diff: {1, 2, 5, 6} # Membership test (fast) print(3 in A) # True # Auto-removes duplicates nums = {1, 2, 2, 3, 3, 3} print(nums) # {1, 2, 3}
