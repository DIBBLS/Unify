Week 4 of 12 Control Structures

Control structures are what make programs intelligent — they let your code make decisions and repeat actions. This week covers if/elif/else for decisions and for/while loops for repetition.

if/elseeliffor loopwhile looprange()BooleanIndentation

  2. Write a for loop that prints the squares of numbers 1 to 10.
  3. What is the difference between a for loop and a while loop?
Topic 4.1
if / elif / else

if checks a condition. If true, runs the indented block. elif checks another condition. else is the fallback.

score = float(input("Enter score: ")) if score >= 70: print("A — Distinction") elif score >= 60: print("B — Credit") elif score >= 50: print("C — Merit") elif score >= 45: print("D — Pass") else: print("F — Fail")
Common mistake
Forgetting the colon (:) at the end of if/elif/else lines. Also: Python uses indentation (spaces/tabs) to define blocks — inconsistent indentation causes IndentationError.
Topic 4.2
for Loops

for loops iterate over a sequence a known number of times. range(1, 11) generates numbers 1 to 10.

# Print squares 1 to 10 for i in range(1, 11): print(i, "squared =", i ** 2) # Output: 1 squared = 1, 2 squared = 4, ... 10 squared = 100 # Loop through a list fruits = ["mango", "orange", "banana"] for fruit in fruits: print(fruit)
Topic 4.3
while Loops

while loops repeat as long as a condition is true. Use when you don't know how many times in advance.

count = 1 while count <= 5: print("Count:", count) count += 1 # Prints Count: 1 through Count: 5
Common mistake
Infinite loop — forgetting to update the variable inside while. If count never changes, the loop runs forever.
