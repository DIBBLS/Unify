Topic 2.1
Arithmetic Operators

Floor division (//): divides and drops everything after the decimal. 9 // 2 = 4.

Modulus (%): remainder after division. 9 % 2 = 1.

Exponentiation (**): raises to a power. 210 ** 3 = 9,261,000.

print(9 // 2) # Output: 4 print(9 % 2) # Output: 1 print(210 ** 3) # Output: 9261000 print(10 != 9) # Output: True
Common mistake
Confusing // with /: 9/2 = 4.5, 9//2 = 4. Also: 210*3 = 630, 210**3 = 9261000.
Topic 2.2
Bitwise Operators

Bitwise operators work on binary representation. Convert each number to binary, then apply the rule bit by bit.

5 in binary = 101  ·  7 in binary = 111

Bitwise rules
AND (&): both bits must be 1  →  101 & 111 = 101 = 5
OR (|): either bit is 1  →  101 | 111 = 111 = 7
XOR (^): bits must be different  →  101 ^ 111 = 010 = 2
Left shift (<<): multiply by 2 per shift  →  5 << 1 = 10 (101 → 1010)
Right shift (>>): divide by 2 per shift  →  5 >> 1 = 2 (101 → 10)
print(5 & 7) # Output: 5 print(5 | 7) # Output: 7 print(5 ^ 7) # Output: 2 print(5 << 1) # Output: 10 print(5 >> 1) # Output: 2
Common mistake
Thinking ^ means "to the power of" — in Python, ^ is XOR, NOT exponentiation. For powers use **. So 5^7 = 2 (XOR), not 78125.
Topic 2.3
Comparison & Logical Operators

!= means "not equal to". 10 != 9 → True.

and: both conditions must be true. x > 3 and x < 10 with x=5 → True.

print(10 != 9) # Output: True x = 5 print(x > 3 and x < 10) # Output: True
