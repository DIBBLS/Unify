Week 1 of 12 Variables & Naming Rules

Variables are the absolute foundation of Python. This week covers what a variable is, how Python stores data in memory, and the five strict rules for naming them — rules that examiners love to test directly.

Topic 1.1
What Is a Variable?

A variable is a named location used to store data in memory. It acts as a container for holding values that can be referenced and manipulated. You create one by giving it a name and assigning a value with the = sign.

# Creating a variable ECE = 258 print(ECE) # Output: 258
Analogy
Think of a variable like a labelled jar — the jar has a name ("Sugar") and holds something inside. The name is the label; the value is what's inside.
Topic 1.2
The Five Rules for Naming Variables

Rule 1 — Valid Characters Only: Variable names can only contain letters (a–z, A–Z), digits (0–9), and underscores (_). Nothing else.

Rule 2 — Cannot Start with a Digit: The name cannot start with a number.

2ECE = 258 # SyntaxError! ECE2 = 258 # Works perfectly

Rule 3 — Python is Case Sensitive: ECE, ece, Ece are three different variables.

Students_ECE = 258 half_ECE = Students_ECE / 2 print(half_ECE) # Output: 129.0 print(half_ece) # NameError: name 'half_ece' is not defined

Rule 4 — No Reserved Keywords: Words like if, else, elif, for, while, def, return cannot be variable names. But you can modify them: else_1 is fine.

else = 4 # SyntaxError! else_1 = 4 # Works print(else_1 * 2) # Output: 8

Rule 5 — No Special Characters: Characters like #, !, @, % are not allowed.

else!1 = 4 # SyntaxError!

Bonus Rule — Be Descriptive: Use student_count instead of x. Use total_area instead of ta.

Common mistake
Only listing 3 or 4 rules — the question asks for five. Also: mixing cases accidentally (defining half_ECE then typing half_ece). And using else or if as variable names — fix by appending a number: else_1.
Exam answer — write this if asked
Enumerate five conditions for naming a perfect variable: (1) valid characters only, (2) cannot start with a digit, (3) case sensitive, (4) no reserved keywords, (5) no special characters.
