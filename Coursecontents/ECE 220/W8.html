Topic 8.1
Nested Loops

A nested loop is a loop inside another loop. The inner loop completes all its iterations for each single iteration of the outer loop. Used for 2D patterns, tables, and matrix operations.

# Multiplication table 1–5 for i in range(1, 6): # outer: rows for j in range(1, 6): # inner: columns print(i * j, end="\t") # \t = tab spacing print() # newline after each row # Output: # 1 2 3 4 5 # 2 4 6 8 10 # 3 6 9 12 15 # 4 8 12 16 20 # 5 10 15 20 25
# Triangle star pattern for i in range(1, 6): print("* " * i) # Output: # * # * * # * * * # * * * * # * * * * *
Tracing rule
For every 1 outer iteration, the inner loop runs completely. So outer=5, inner=5 means 5×5 = 25 total executions of the innermost statement.
Topic 8.2
String Methods

String methods are built-in functions you call on a string using dot notation: string.method(). They don't change the original string — they return a new one.

Essential string methods for the exam
.upper() — convert to uppercase: "hello".upper() → "HELLO"
.lower() — convert to lowercase: "HELLO".lower() → "hello"
.strip() — remove leading/trailing spaces: " hi ".strip() → "hi"
.replace(old, new) — swap substring: "cat".replace("c","b") → "bat"
.split() — split into list of words: "a b c".split() → ["a","b","c"]
.join(list) — join list into string: "-".join(["a","b"]) → "a-b"
len(s) — number of characters: len("hello") → 5
# Chaining methods result = " Hello World ".strip().lower().replace("world", "Python") print(result) # hello Python # Count words in a sentence sentence = input("Enter sentence: ") words = sentence.split() print(f"Word count: {len(words)}") # Palindrome check word = input("Enter a word: ").lower().strip() if word == word[::-1]: print(f"{word} is a palindrome") else: print(f"{word} is NOT a palindrome")
Common mistake
String methods don't modify in place. name.upper() does NOT change name — you must assign: name = name.upper(). Strings in Python are immutable.
