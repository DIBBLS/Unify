Week 11 of 12 Algorithms, Searching & Sorting

An algorithm is a step-by-step solution to a problem. This week covers linear search, bubble sort, and how to find min/max/sum in a list using loops. These are the kind of "write the code from scratch" questions that appear in Section B of the exam.

Topic 11.1
Linear Search

Linear search checks each element one by one from the beginning until it finds the target or reaches the end. Simple but works on any list (sorted or not).

def linear_search(lst, target): for i in range(len(lst)): if lst[i] == target: return i # return index where found return -1 # -1 means not found numbers = [14, 3, 27, 9, 42] target = int(input("Search for: ")) pos = linear_search(numbers, target) if pos != -1: print(f"{target} found at index {pos}") else: print(f"{target} not in list")
Topic 11.2
Bubble Sort

Bubble sort repeatedly compares adjacent pairs and swaps them if they're in the wrong order. After each pass, the largest unsorted element "bubbles" to its correct position.

def bubble_sort(lst): n = len(lst) for i in range(n): # passes for j in range(n - i - 1): # comparisons per pass if lst[j] > lst[j + 1]: # swap lst[j], lst[j + 1] = lst[j + 1], lst[j] return lst nums = [64, 25, 12, 22, 11] print(bubble_sort(nums)) # [11, 12, 22, 25, 64]
Pass-by-pass trace for [64, 25, 12]
Start: [64, 25, 12]
Pass 1: 64>25 → swap → [25, 64, 12]; 64>12 → swap → [25, 12, 64]
Pass 2: 25>12 → swap → [12, 25, 64]
Result: [12, 25, 64] ✓
Topic 11.3
Finding Min, Max & Sum Without Built-ins

The exam sometimes asks you to find max/min manually (without max()) to test whether you understand loops.

# Manual max without using max() def find_max(lst): largest = lst[0] # assume first is largest for num in lst: if num > largest: largest = num return largest scores = [72, 85, 61, 90, 78] print(find_max(scores)) # 90 # Python built-ins (know these too) print(max(scores)) # 90 print(min(scores)) # 61 print(sum(scores)) # 386 print(sorted(scores)) # [61, 72, 78, 85, 90] scores.sort() # modifies in place
sort() vs sorted()
list.sort() — modifies the original list in place, returns None
sorted(list) — returns a NEW sorted list, original unchanged
Use sorted() when you need both the original and sorted version.
