Week 6 of 12 Functions & Libraries

Functions let you write code once and reuse it anywhere. Libraries extend Python with pre-built tools. Together they are the foundation of writing real, maintainable programs.

Topic 6.1
Defining Functions with def

A function is a reusable block of code. Define it with def, then call it by name.

def greet(name): print("Hello,", name + "!") greet("Mumuni") # Hello, Mumuni! greet("ECE 220") # Hello, ECE 220!
Topic 6.2
Parameters, Arguments & Return

Parameters are variables in the function definition. Arguments are the actual values passed in. return sends a value back to the caller.

def calculate_area(length, width): area = length * width return area result = calculate_area(5, 3) print("Area:", result) # Area: 15 def get_larger(a, b): if a >= b: return a else: return b print(get_larger(10, 7)) # 10 print(get_larger(3, 9)) # 9
Topic 6.3
Built-in Functions

Python comes with many built-in functions: len(), range(), int(), float(), str(), type(), abs(), round(), max(), min(), sum().

numbers = [4, 7, 2, 9, 1] print(len(numbers)) # 5 print(max(numbers)) # 9 print(min(numbers)) # 1 print(sum(numbers)) # 23 print(round(3.7)) # 4
Topic 6.4
Importing Libraries

Use import to bring in a library. The math library has sqrt(), pi, pow(), floor(), ceil().

import math print(math.sqrt(144)) # 12.0 print(math.pi) # 3.14159... print(math.floor(4.9)) # 4 print(math.ceil(4.1)) # 5 import random print(random.randint(1, 10)) # Random int between 1 and 10
Common mistake
Calling a function before defining it — Python reads top to bottom. Also: forgetting return — without it, the function returns None.
