Week 3 of 12 Input, Output & Programs

This week covers how Python communicates with the user — the print() function for output and input() for reading user data. Type conversion is critical: everything from input() comes as a string and must be converted before arithmetic.

Likely exam questions
Exam focus
  1. Write a Python program that accepts user input for test score, assignment score, and attendance. 2024/2025 Q1d
  2. What data type does input() always return?
Topic 3.1
The print() Function

print() displays output to the screen. Can print text (strings), numbers, variables, and expressions.

print("Hello, ECE 220!") # Output: Hello, ECE 220! name = "Mumuni" age = 3 print("Name:", name, "Year:", age) # Name: Mumuni Year: 3 print("2 + 2 =", 2 + 2) # 2 + 2 = 4
Topic 3.2
The input() Function

input() pauses the program and waits for the user to type something. It ALWAYS returns a string.

name = input("Enter your name: ") print("Hello,", name)
Common mistake
Trying to do arithmetic directly on an input() result:
age = input("Enter your age: ") next_year = age + 1 # TypeError! Can't add string and int
Fix with type conversion:
age = int(input("Enter your age: ")) next_year = age + 1 # Works: 22 if age is 21
Topic 3.3
Type Conversion

int() converts to integer. float() converts to decimal. str() converts to string.

test_score = float(input("Enter test score: ")) assignment_score = float(input("Enter assignment score: ")) attendance = float(input("Enter attendance %: ")) final = (test_score + (2 * assignment_score)) / 3 + (5 if attendance >= 90 else 0) print("Final Score:", final)
Topic 3.4
The Ternary (Conditional) Expression

Shorthand for if/else in one line: value_if_true if condition else value_if_false

bonus = 5 if attendance >= 90 else 0 # Same as: # if attendance >= 90: # bonus = 5 # else: # bonus = 0
Key fact — write this verbatim
input() always returns a string. You must use int() or float() to convert it before arithmetic.
