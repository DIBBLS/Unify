Topic 10.1
Defining and Calling Functions

A function is a named, reusable block of code. Define it once with def, call it anywhere. Functions can accept inputs (parameters) and send back results (return).

Parameter vs Argument
Parameter — the variable name inside the function definition: def greet(name) — here name is the parameter.
Argument — the actual value you pass when calling: greet("Amaka") — here "Amaka" is the argument.
# Basic function — no return value def greet(name): print(f"Hello, {name}! Welcome to ECE 220.") greet("Amaka") # Hello, Amaka! Welcome to ECE 220. greet("Bola") # Hello, Bola! Welcome to ECE 220. # Function WITH return value def add(a, b): return a + b result = add(10, 25) print(result) # 35 # Grade function — exam favourite def calculate_grade(score): if score >= 70: return "A" elif score >= 60: return "B" elif score >= 50: return "C" elif score >= 45: return "D" else: return "F" print(calculate_grade(75)) # A print(calculate_grade(52)) # C
Common mistake
Forgetting return. A function without a return statement returns None. So result = add(3, 4) where add has no return gives result = None, not 7.
Topic 10.2
Default Parameters & Scope

A default parameter has a preset value that's used if no argument is passed for that position. Scope determines where a variable is visible.

# Default parameters def power(base, exp=2): # exp defaults to 2 return base ** exp print(power(3)) # 9 (3² — uses default) print(power(3, 3)) # 27 (3³ — overrides default) # Scope: local vs global x = 10 # global variable def show(): y = 20 # local variable — only exists inside show() print(x, y) # can access global x show() # 10 20 # print(y) ← NameError: y is not defined here
Topic 10.3
Recursion

A recursive function calls itself. Every recursive function needs a base case (stopping condition) to prevent infinite recursion.

# Factorial using recursion def factorial(n): if n == 0 or n == 1: # base case return 1 return n * factorial(n - 1) # recursive call print(factorial(5)) # 120 (5×4×3×2×1) print(factorial(0)) # 1 (base case) # Trace for factorial(4): # factorial(4) → 4 × factorial(3) # factorial(3) → 3 × factorial(2) # factorial(2) → 2 × factorial(1) # factorial(1) → 1 ← base case # Unwinds: 2×1=2, 3×2=6, 4×6=24
