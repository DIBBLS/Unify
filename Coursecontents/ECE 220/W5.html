Week 5 of 12 Expressions Deep Dive: Lists, Tuples & Nested Expressions

Lists and tuples are Python's two main sequence types. The 2024/2025 exam directly asked students to compare them (Q1a). The nested expression in Q1d (the grading formula) is also this week's territory.

Topic 5.1
Lists

A list is a mutable, ordered collection. Created with square brackets []. You can change, add, or remove elements.

my_list = [7, 8, 10] my_list[0] = 99 # Change first element print(my_list) # [99, 8, 10] my_list.append(5) # Add to end print(my_list) # [99, 8, 10, 5]
Topic 5.2
Tuples

A tuple is an immutable, ordered collection. Created with parentheses (). Once created, cannot be changed.

my_tuple = (7, 8, 10) print(my_tuple[0]) # 7 (indexing works) my_tuple[0] = 99 # TypeError! Cannot modify tuple
Analogy
A list is like a shopping cart (you can add/remove items). A tuple is like a printed receipt (fixed forever after printing).
Topic 5.3
List vs Tuple Comparison — Exam Q1a

Similarities: Both store multiple items. Both support indexing. Both can hold mixed data types. Both support for loops.

Differences (exam table)
Syntax: Lists use []  ·  Tuples use ()
Mutability: Lists are mutable (elements can change)  ·  Tuples are immutable (cannot change after creation)
Performance: Tuples are slightly faster (less overhead)
Use case: Lists for data that changes  ·  Tuples for fixed data (coordinates, RGB values)
my_list = [7, 8, 10] my_list[0] = 99 # Works! Now [99, 8, 10] my_tuple = (7, 8, 10) my_tuple[0] = 99 # TypeError! Cannot modify
Topic 5.4
Nested Expressions

A nested expression is an expression inside another expression. Python evaluates the innermost part first.

test_score = float(input("Test score (max 55): ")) assignment_score = float(input("Assignment (max 10): ")) attendance = float(input("Attendance %: ")) final_score = (test_score + (2 * assignment_score)) / 3 + (5 if attendance >= 90 else 0) print("Final Score:", final_score) # Example: test=45, assignment=8, attendance=92 # (45 + 16) / 3 + 5 = 61/3 + 5 = 20.33 + 5 = 25.33
Common mistake
Confusing [] (list) with () (tuple). Also: the conditional expression (ternary) — write value_if_true if condition else value_if_false, not the other way round.
