Topic 1
Legendre's Differential Equation

Legendre's equation appears in many physical problems — heat conduction in spheres, gravitational fields, quantum mechanics. It is a second-order linear ODE with a polynomial coefficient:

Legendre's Equation
\[ (1-x^2)y'' - 2xy' + k(k+1)y = 0 \]
where \(k\) is a non-negative integer. The equation has an ordinary point at \(x = 0\), so the power series method applies.
1.1

The Series Solution & Coefficient Recurrence

The solution to Legendre's equation is a power series. When \(k\) is a non-negative integer, the series terminates — it stops after a finite number of terms and becomes a polynomial. These are called the Legendre polynomials, denoted \(P_k(x)\).

The convention is to normalise each polynomial so that \(P_k(1) = 1\). This fixes the arbitrary constant and gives clean, standard forms.

Coefficient Recurrence for Legendre's Equation
\[ a_{n+2} = -\frac{(k-n)(k+n+1)}{(n+1)(n+2)}\, a_n \]
Even-indexed coefficients build from \(a_0\); odd-indexed from \(a_1\). When \(n = k\), the numerator becomes zero — the series terminates.
💡 Why does the series terminate?

The recurrence multiplies each term by \((k-n)\). When \(n\) reaches \(k\), this factor becomes zero — so \(a_{k+2} = 0\), and all subsequent coefficients vanish. The infinite series becomes a finite polynomial of degree \(k\).

In the recurrence \(a_{n+2} = -\frac{(k-n)(k+n+1)}{(n+1)(n+2)} a_n\), why does the series terminate when \(k\) is a non-negative integer?
When \(n = k\), the factor \((k - n) = 0\) in the numerator makes \(a_{k+2} = 0\). All subsequent coefficients are also zero, so the infinite series collapses to a finite polynomial of degree \(k\).
Topic 2
The Legendre Polynomials \(P_k(x)\)
2.1

Explicit Forms of \(P_0\) through \(P_3\)

By convention: when \(k\) is even, set \(a_1 = 0\) and choose \(a_0\) so that \(P_k(1) = 1\). When \(k\) is odd, set \(a_0 = 0\) and choose \(a_1\) so that \(P_k(1) = 1\).

P₀(x) — degree 0
\[ P_0(x) = 1 \]
P₁(x) — degree 1
\[ P_1(x) = x \]
P₂(x) — degree 2
\[ P_2(x) = \tfrac{1}{2}(3x^2 - 1) \]
P₃(x) — degree 3
\[ P_3(x) = \tfrac{1}{2}(5x^3 - 3x) \]
Key pattern:

Even-degree polynomials (\(P_0, P_2, P_4, \ldots\)) contain only even powers of \(x\). Odd-degree ones (\(P_1, P_3, P_5, \ldots\)) contain only odd powers. The two independent series never mix — even from \(a_0\), odd from \(a_1\).

Topic 3
Worked Examples — Deriving the Polynomials
3.1

Finding \(P_1(x)\) and \(P_2(x)\)

Example 1 — Finding P₁(x) and P₂(x)
From the solution series of Legendre's equation, find \(P_1(x)\) and \(P_2(x)\) explicitly.
1
For \(k = 1\) (odd), set \(a_0 = 0\), use \(a_1\) as the free constant.
Recurrence at \(n=1\): \(a_3 = -\frac{(1-1)(3)}{2 \times 3} a_1 = 0\). Series terminates!
So: \(y = a_1 x\). Normalising: \(P_1(1) = a_1 = 1 \Rightarrow a_1 = 1\)
\[ P_1(x) = x \]
2
For \(k = 2\) (even), set \(a_1 = 0\), use \(a_0\) as the free constant.
At \(n=0\): \(a_2 = -\frac{(2)(3)}{2} a_0 = -3a_0\)
At \(n=2\): \(a_4 = -\frac{(0)(5)}{12} a_2 = 0\). Terminates.
Series: \(y = a_0(1 - 3x^2)\). Normalising at \(x=1\): \(a_0(1-3) = 1 \Rightarrow a_0 = -\frac{1}{2}\)
\[ P_2(x) = -\tfrac{1}{2}(1 - 3x^2) = \tfrac{1}{2}(3x^2 - 1) \]
3.2

Finding \(P_3(x)\)

Example 2 — Finding P₃(x)
Derive \(P_3(x)\) using the power series recurrence for \(k = 3\) (odd, so use \(a_0 = 0\)).
1
For \(k=3\), \(a_0 = 0\), free constant is \(a_1\).
At \(n=1\): \(a_3 = -\frac{(3-1)(3+1+1)}{2 \times 3} a_1 = -\frac{2 \times 5}{6} a_1 = -\frac{5}{3} a_1\)
At \(n=3\): \(a_5 = 0\). Series: \(y = a_1\left(x - \frac{5}{3}x^3\right)\)
2
Normalise: \(P_3(1) = a_1\left(1 - \frac{5}{3}\right) = a_1\left(-\frac{2}{3}\right) = 1 \Rightarrow a_1 = -\frac{3}{2}\)
\[ P_3(x) = -\tfrac{3}{2}\!\left(x - \tfrac{5}{3}x^3\right) = \tfrac{1}{2}(5x^3 - 3x) \]

Verification at x = 1 — every Legendre polynomial satisfies \(P_k(1) = 1\) by construction:

  • \(P_0(1) = 1\) ✓
  • \(P_1(1) = 1\) ✓
  • \(P_2(1) = \frac{1}{2}(3-1) = 1\) ✓
  • \(P_3(1) = \frac{1}{2}(5-3) = 1\) ✓

Topic Active Recall
Definition
State Legendre's differential equation in standard form.
\[(1-x^2)y'' - 2xy' + k(k+1)y = 0\] where \(k\) is a non-negative integer. This is the standard form you must be able to write from memory.
Mechanism
Why does the power series solution terminate when \(k\) is a non-negative integer?
The recurrence is \(a_{n+2} = -\frac{(k-n)(k+n+1)}{(n+1)(n+2)} a_n\). When \(n = k\), the factor \((k-n) = 0\), making \(a_{k+2} = 0\). All subsequent coefficients are also zero — the infinite series becomes a finite polynomial of degree \(k\).
Computation
Write \(P_2(x)\) and verify \(P_2(1) = 1\).
\(P_2(x) = \frac{1}{2}(3x^2 - 1)\)

Checking: \(P_2(1) = \frac{1}{2}(3 - 1) = \frac{1}{2}(2) = 1\) ✓
Application
How do you decide whether to set \(a_0 = 0\) or \(a_1 = 0\) when finding a Legendre polynomial?
If \(k\) is even → set \(a_1 = 0\), keep \(a_0\) as the free constant (even powers only). If \(k\) is odd → set \(a_0 = 0\), keep \(a_1\) as the free constant (odd powers only). Then normalise so that \(P_k(1) = 1\).
