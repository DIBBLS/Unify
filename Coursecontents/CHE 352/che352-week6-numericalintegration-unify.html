Topic 1
Why Numerical Integration?
1.1

Motivation & Approach

Many real-world integrals cannot be solved analytically — the function has no closed-form antiderivative, or you only have data points (not a formula). Numerical integration gives you an approximate value of \(\int_a^b f(x)\,dx\) using function values at a set of equally spaced points.

The two methods in this course approximate the area under a curve by dividing it into strips and fitting simple shapes to each strip:

  • Trapezoidal Rule — fits a straight line (trapezoid) between each pair of adjacent points
  • Simpson's Rule — fits a parabola through each group of three points — more accurate

Topic 2
The Trapezoidal Rule
2.1

Formula & Worked Example

Divide \([a, b]\) into \(n\) equal sub-intervals of width \(h = \frac{b-a}{n}\). On each strip, approximate the curve as a straight line — forming a trapezoid. Sum all the trapezoid areas.

Trapezoidal Rule
\[ I = \int_a^b f(x)\,dx \approx \frac{h}{2}\left[(y_0 + y_n) + 2(y_1 + y_2 + \cdots + y_{n-1})\right] \]
\(h = \dfrac{b-a}{n}\), \(n\) = number of sub-intervals, \(y_i = f(x_i)\).
\(y_0\) and \(y_n\) are the first and last ordinates. All middle ones are multiplied by 2.
💡 Analogy

Think of painting a fence with a jagged top. Instead of measuring every curve, you approximate each panel as a straight line from post to post. More posts (higher \(n\)) → more accurate total area estimate.

Evaluate \(\displaystyle\int_0^1 x^3\,dx\) using the Trapezoidal Rule with 5 sub-intervals.
1

\(a = 0\), \(b = 1\), \(n = 5\) \(\Rightarrow h = \dfrac{1-0}{5} = 0.2\)
2

Topic 3
Simpson's Rule
3.1

Formula & F+L/E/R Classification

Simpson's Rule is more accurate than the Trapezoidal Rule because instead of fitting straight lines, it fits parabolas through groups of three consecutive points — better capturing curvature.

Important: n must be even for Simpson's Rule to work — you need pairs of strips to fit a parabola.

Simpson's Rule — General Formula
\[ A \approx \frac{s}{3}\left[(F+L) + 4E + 2R\right] \]
\(s\) = width of each strip (same as \(h\))
\(F + L\) = sum of the first and last ordinates
\(4E\) = 4 × sum of all odd-positioned middle ordinates (\(y_1, y_3, y_5, \ldots\))
\(2R\) = 2 × sum of all even-positioned middle ordinates (\(y_2, y_4, y_6, \ldots\))
Note: positions are counted from \(y_1\), not from \(y_0\).
⚠️ E and R classification — common exam trap

Start counting from \(y_1\). \(y_1, y_3, y_5, \ldots\) go into \(4E\). \(y_2, y_4, y_6, \ldots\) go into \(2R\). \(y_0\) and \(y_n\) are always F and L. Get this right before computing anything.

3.2

Worked Example — Pin Velocity (Simpson's)

Example 3.2 — Pin velocity problem
A pin moves along a straight guide. Its velocity \(v\) (cm/s) at time \(t\) (s) is given below. Find the distance travelled using Simpson's Rule.
\(t\) (s)00.51.01.52.02.53.03.54.0
\(v\) (cm/s)047.9411.6814.9717.3918.2516.080
1
Classify ordinates. \(s = 0.5\), 8 strips (even ✓).
\(F+L = 0 + 0 = 0\)
\(E\) (positions 1, 3, 5, 7): \(4 + 11.68 + 17.39 + 16.08 = 49.15\)
\(R\) (positions 2, 4, 6): \(7.94 + 14.97 + 18.25 = 41.16\)
2
Apply Simpson's formula. \[ A = \frac{0.5}{3}\left[0 + 4(49.15) + 2(41.16)\right] = \frac{0.5}{3}\left[196.6 + 82.32\right] = \frac{0.5}{3} \times 278.92 \]
\[ A \approx 46.49 \text{ cm} \]

Recall Questions
Definition
Write the Trapezoidal Rule formula from memory.
\[I = \frac{h}{2}\left[(y_0 + y_n) + 2(y_1 + y_2 + \cdots + y_{n-1})\right]\] First + last ordinate in one bracket, all middle ordinates doubled in another.
Definition
Write Simpson's Rule formula and define F+L, E, and R.
\[A \approx \frac{s}{3}\left[(F+L) + 4E + 2R\right]\] F+L: first + last ordinate. 4E: 4 × sum of odd-positioned middles (\(y_1, y_3, y_5, \ldots\)). 2R: 2 × sum of even-positioned middles (\(y_2, y_4, \ldots\)).
Mechanism
Why must n be even for Simpson's Rule?
Simpson's Rule fits a parabola through every group of 3 consecutive points (2 strips). With an odd number of strips, the pairing breaks down and you can't fit complete parabolas across the interval.
Computation
For the pin problem with \(s=0.5\), \(F+L=0\), \(E=49.15\), \(R=41.16\) — what is \(A\)?
\[A = \frac{0.5}{3}\left[0 + 4(49.15) + 2(41.16)\right] = \frac{0.5}{3}(278.92) \approx 46.49 \text{ cm}\]
