Topic 1
What Is Interpolation?
1.1

Definition & Methods

Interpolation is the process of estimating the value of a function at a point that lies between known data points. Given a table of \((x, f(x))\) values, you can use interpolation to find \(f(x)\) at an intermediate \(x\) without measuring it directly.

This matters in engineering whenever you have discrete measurements — sensor readings, experimental results, tabulated data — and need values between those measurements.

There are three methods covered this week:

  • Linear Interpolation — assumes a straight line between two adjacent data points
  • Graphical Interpolation — plots the data and reads off the value visually
  • Gregory-Newton Forward Difference — uses finite differences to fit a polynomial through all the data
💡 Interpolation vs Extrapolation

Interpolation estimates values between known data points. Extrapolation estimates values beyond the range of the data — much less reliable and not covered here.

Topic 2
Linear Interpolation
2.1

The Linear Formula & Worked Example

Linear interpolation assumes the function varies linearly between two adjacent known points. Given two points \((x_1, y_1)\) and \((x_2, y_2)\), the value at any \(x\) between them is found by the straight-line relationship:

Linear Interpolation Formula
\[ \frac{x - x_1}{x_2 - x_1} = \frac{y - y_1}{y_2 - y_1} \]
Rearrange to solve for \(y\). This is the equation of a straight line through two points.
Example — Linear Interpolation
Given the data table below, use linear interpolation to find \(f(2.5)\).
x123456
f(x)414?4088164
1
Identify the two surrounding points.
\(x = 2.5\) lies between \(x_1 = 2\) (\(y_1 = 14\)) and \(x_2 = 3\) (\(y_2 = 40\)).
2
Set up the equation. \[ \frac{2.5 - 2}{3 - 2} = \frac{y - 14}{40 - 14} \implies \frac{0.5}{1} = \frac{y - 14}{26} \]
3
Solve for \(y\). \[ y - 14 = 0.5 \times 26 = 13 \implies y = 27 \]
\[ f(2.5) \approx 27 \quad \text{(linear interpolation)} \]

What assumption does linear interpolation make about the function between two data points?
It assumes the function varies as a straight line between the two points. This is why it overshoots the true value when the actual function is curved.

Graphical Interpolation
3.1

Reading from a Curve

Graphical interpolation uses the same data to plot a smooth curve through the points and read off the value at the desired \(x\). It is the least precise method but gives a quick visual estimate.

Using the data table (x = 1 to 6, f(x) = 4 to 164), plot the points and draw a smooth curve. At \(x = 2.5\), read the \(y\)-value from the curve.

Compare methods so far:

Linear interpolation gave \(f(2.5) = 27\). Graphical gave \(f(2.5) \approx 26\). The actual value (from Gregory-Newton) is 24.625 — graphical is closer here because it captures the curve's shape, while linear overshoots by assuming a straight line.

Why is graphical interpolation less precise than Gregory-Newton?
It relies on a visual estimate — you read a value off a hand-drawn curve. Gregory-Newton uses all the data differences systematically and produces an exact polynomial answer. The eye cannot precisely read the y-value off a graph.
Topic 4
Gregory-Newton Forward Difference Interpolation
4.1

Formula, Difference Table & Worked Example

The Gregory-Newton method fits a polynomial through all the data points using a finite difference table. The formula uses successive differences — \(\Delta f\), \(\Delta^2 f\), \(\Delta^3 f\) — computed from the data.

Required: uniformly spaced data (equal intervals between x-values).

Gregory-Newton Forward Difference Formula
\[ f_p = f_0 + p\,\Delta f_0 + \frac{p(p-1)}{2!}\,\Delta^2 f_0 + \frac{p(p-1)(p-2)}{3!}\,\Delta^3 f_0 + \cdots \]
where \(p = \dfrac{x_p - x_0}{h}\) and \(h\) is the constant interval between successive \(x\)-values.
\(\Delta f_0, \Delta^2 f_0, \Delta^3 f_0\) = first, second, third forward differences at \(x_0\).
Building the table: \(\Delta f_i = f(x_{i+1}) - f(x_i)\); \(\Delta^2 f_i = \Delta f_{i+1} - \Delta f_i\); and so on.

2
Identify starting values.
Closest \(x_0\) before 2.5 is \(x_0 = 2\). \(h = 1\), so: \[ p = \frac{2.5 - 2}{1} = 0.5 \] From row at \(x_0 = 2\): \(f_0 = 14,\ \Delta f_0 = 26,\ \Delta^2 f_0 = 22,\ \Delta^3 f_0 = 6\)
3
Substitute into the formula. \[ f_p = 14 + (0.5)(26) + \frac{(0.5)(-0.5)}{2}(22) + \frac{(0.5)(-0.5)(-1.5)}{6}(6) \]
4
Evaluate each term.
Term 1: \(14\)
Term 2: \(0.5 \times 26 = 13\)
Term 3: \(\dfrac{-0.25}{2} \times 22 = -0.125 \times 22 = -2.75\)
Term 4: \(\dfrac{0.375}{6} \times 6 = 0.375\)
5
Sum all terms. \[ f_p = 14 + 13 + (-2.75) + 0.375 = 24.625 \]
\[ f(2.5) = 24.625 \quad \text{(Gregory-Newton)} \] More accurate than linear (27) and graphical (≈26) because it uses all the data.

Recall Questions
Definition
What is interpolation, and how does it differ from extrapolation?
Interpolation estimates values between known data points. Extrapolation estimates values beyond the data range. Interpolation is reliable; extrapolation is not — the polynomial fit may behave very differently outside the data range.
Mechanism
How is the forward difference table built? Describe one step.
Each column is built by subtracting adjacent values in the column to its left. First differences: \(\Delta f_i = f_{i+1} - f_i\). Second differences: \(\Delta^2 f_i = \Delta f_{i+1} - \Delta f_i\). The table narrows by one row with each new column.
Application
In the Gregory-Newton formula, how do you compute \(p\) when finding \(f(2.5)\) with \(x_0 = 2\) and \(h = 1\)?
\[p = \frac{x_p - x_0}{h} = \frac{2.5 - 2}{1} = 0.5\] \(p\) is always between 0 and 1 when interpolating between two adjacent data points.
Computation
For the Example 3 data, what are \(f_0\), \(\Delta f_0\), \(\Delta^2 f_0\), and \(\Delta^3 f_0\) at \(x_0 = 2\)?
\(f_0 = 14\), \(\Delta f_0 = 26\), \(\Delta^2 f_0 = 22\), \(\Delta^3 f_0 = 6\). Read across the row at \(x = 2\) in the forward difference table.
