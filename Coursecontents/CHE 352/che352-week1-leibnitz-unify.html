Topic 1
Successive Differentiation

When you differentiate a function \(y = f(x)\) once, you get \(y_1 = \frac{dy}{dx}\). Differentiate again and you get \(y_2 = \frac{d^2y}{dx^2}\). Differentiating repeatedly like this is called successive differentiation, and the result of differentiating \(n\) times is written \(y_n\) or \(\frac{d^ny}{dx^n}\).

The challenge comes when \(y\) is a product of two functions — say \(y = u \cdot v\). You can't just differentiate one part. You need to account for both, and their interaction across all \(n\) derivatives. That's exactly what Leibnitz Theorem solves.

1.1

The Leibnitz Theorem

If \(y = u \cdot v\) where both \(u\) and \(v\) are functions of \(x\), then the \(n\)th derivative of \(y\) is given by:

Leibnitz Theorem — nth Derivative of a Product
\[ y_n = \sum_{k=0}^{n} \binom{n}{k} u_{n-k} \, v_k \]
Written out in full:
\[ y_n = u_n v + n u_{n-1} v_1 + \frac{n(n-1)}{2!} u_{n-2} v_2 + \frac{n(n-1)(n-2)}{3!} u_{n-3} v_3 + \cdots \]
where \(u_k = \frac{d^k u}{dx^k}\) and \(v_k = \frac{d^k v}{dx^k}\). The coefficients are binomial coefficients \(\binom{n}{k}\).
💡 Why does it look like the binomial expansion?

The pattern is not a coincidence. When you expand \((u + v)^n\), you get binomial coefficients. The Leibnitz formula has the exact same structure — but instead of powers, you're taking derivatives. Each term pairs a derivative of \(u\) with a derivative of \(v\), the same way each binomial term pairs powers of \(u\) and \(v\).

1.2

Setting up the Recurrence Relation

For ODEs of the form \(f(x) \cdot y'' + g(x) \cdot y' + h(x) \cdot y = 0\), the approach is:

  1. Differentiate the equation \(n\) times using Leibnitz Theorem on each product term
  2. Express everything in terms of \(y_n\), \(y_{n+1}\), \(y_{n+2}\)
  3. This gives a recurrence relation — a formula that lets you find \(y_n\) from earlier values
  4. Use initial conditions (values at \(x = 0\)) to compute \(y_0, y_1, y_2, \ldots\) step by step

Once you have the recurrence relation, what happens when you set \(x = 0\) and the ODE has the form \((1+x^2)y_{n+2} + 2(n+1)xy_{n+1} + (n^2+n-5)y_n = 0\)?
At \(x = 0\), all terms multiplied by \(x\) vanish. The relation simplifies to \(y_{n+2} = (5 - n^2 - n)y_n\). This gives a much simpler two-step recurrence that lets you compute even-indexed derivatives from \(y_0\) and odd-indexed derivatives from \(y_1\), step by step.
Topic 1 Active Recall
Definition
State the Leibnitz Theorem formula for the nth derivative of a product \(y = uv\).
\[ y_n = u_n v + n u_{n-1} v_1 + \frac{n(n-1)}{2!} u_{n-2} v_2 + \frac{n(n-1)(n-2)}{3!} u_{n-3} v_3 + \cdots \] The coefficients are binomial coefficients \(\binom{n}{k}\). Terms stop once you exhaust the non-zero derivatives of either \(u\) or \(v\).
Mechanism
When applying Leibnitz to \((1+x^2)y''\), what happens to derivatives of \(u = 1+x^2\) beyond \(u_2\)?
They vanish. \(u = 1+x^2\), \(u_1 = 2x\), \(u_2 = 2\), and \(u_k = 0\) for all \(k \geq 3\). This is why the Leibnitz expansion for this term only produces three non-zero terms, not an infinite series — making the computation tractable.
Application
For \((1+x^2)y_{n+2} + 2(n+1)xy_{n+1} + (n^2+n-5)y_n = 0\), what does the recurrence relation become at \(x = 0\)?
At \(x = 0\), the terms containing \(x\) vanish: \[ y_{n+2} = (5 - n^2 - n)y_n \] This simplified recurrence lets you compute \(y_2, y_4, y_6, \ldots\) step by step from \(y_0\), and \(y_3, y_5, \ldots\) step by step from \(y_1\).
Computation
If \(y_0 = 1\), \(y_1 = 0\) and the recurrence is \(y_{n+2} = (5-n^2-n)y_n\), what is \(y_4\)?
First compute \(y_2\): \(y_2 = (5 - 0 - 0)(1) = 5\)

Then compute \(y_4\): \(y_4 = (5 - 4 - 2)(5) = (-1)(5) = -5\)

Worked Examples
Example 1
If \((1+x^2)y'' + 2xy' - 5y = 0\), show that \((1+x^2)y_{n+2} + 2(n+1)xy_{n+1} + (n^2+n-5)y_n = 0\)

We apply Leibnitz theorem to each product term in the ODE. Let \(P = (1+x^2)y''\), \(Q = 2xy'\), \(W = 5y\).

1
Differentiate \(P = (1+x^2)y''\) n times.
Let \(u = 1+x^2\), \(v = y''\). Then \(u_1 = 2x\), \(u_2 = 2\), \(u_k = 0\) for \(k \geq 3\).
By Leibnitz: \[ P_n = u_n v + n u_{n-1} v_1 + \frac{n(n-1)}{2!} u_{n-2} v_2 \] \[ P_n = (1+x^2)y_{n+2} + n(2x)y_{n+1} + \frac{n(n-1)}{2}(2)y_n \] \[ P_n = (1+x^2)y_{n+2} + 2nx \cdot y_{n+1} + n(n-1)y_n \]
2
Differentiate \(Q = 2xy'\) n times.
Let \(u = 2x\), \(v = y'\). Then \(u_1 = 2\), \(u_k = 0\) for \(k \geq 2\).
\[ Q_n = (2x)y_{n+1} + n(2)y_n = 2xy_{n+1} + 2ny_n \]
3
Differentiate \(W = 5y\) n times.
\[ W_n = 5y_n \]
4
Combine: \(P_n + Q_n - W_n = 0\) \[ (1+x^2)y_{n+2} + 2nx \cdot y_{n+1} + n(n-1)y_n + 2xy_{n+1} + 2ny_n - 5y_n = 0 \] \[ (1+x^2)y_{n+2} + 2(n+1)xy_{n+1} + [n(n-1) + 2n - 5]y_n = 0 \]
\[ (1+x^2)y_{n+2} + 2(n+1)xy_{n+1} + (n^2 + n - 5)y_n = 0 \]
Example 2
Using the recurrence from Example 1, find \(y_n\) at \(x = 0\) given \(y_0 = 1\), \(y_1 = 0\).

From Example 1, the recurrence relation at \(x = 0\) becomes:

1
At \(x = 0\): \((1+0)y_{n+2} + 0 + (n^2+n-5)y_n = 0\) \[ y_{n+2} = -(n^2+n-5)y_n = (5-n^2-n)y_n \]
2
Compute values step by step using even \(n\) (since \(y_1 = 0\) kills odd terms):
\(n=0\): \(y_2 = (5-0-0)y_0 = 5(1) = 5\)
\(n=2\): \(y_4 = (5-4-2)y_2 = (-1)(5) = -5\)
\(n=4\): \(y_6 = (5-16-4)y_4 = (-15)(-5) = 75\)
Pattern check:

All odd derivatives \(y_1, y_3, y_5, \ldots = 0\) because \(y_1 = 0\) propagates through odd-indexed terms via the recurrence \(y_{n+2} \propto y_n\). Only even derivatives survive.

Example 3
If \(x^2y'' + xy' + y = 0\), apply Leibnitz theorem and find the nth derivative recurrence.
1
Let \(P = x^2 y''\), \(Q = xy'\), \(W = y\).
For \(P\): \(u = x^2\), \(u_1 = 2x\), \(u_2 = 2\), \(u_k = 0\) for \(k \geq 3\). \[ P_n = x^2 y_{n+2} + n(2x)y_{n+1} + \frac{n(n-1)}{2}(2)y_n = x^2 y_{n+2} + 2nx\,y_{n+1} + n(n-1)y_n \]
2
For \(Q = xy'\): \(u = x\), \(u_1 = 1\), \(u_k = 0\) for \(k \geq 2\). \[ Q_n = xy_{n+1} + ny_n \]
3
\(W_n = y_n\). Summing \(P_n + Q_n + W_n = 0\): \[ x^2 y_{n+2} + (2n+1)xy_{n+1} + (n^2+1)y_n = 0 \]
Recurrence: \[ y_{n+2} = \frac{-(n^2+1)y_n - (2n+1)xy_{n+1}}{x^2} \] At \(x = 0\), use L'Hôpital's rule or series methods to handle the singularity.

In Example 2, why do all odd-indexed derivatives \(y_1, y_3, y_5, \ldots\) vanish when \(y_1(0) = 0\)?
Because the recurrence at \(x = 0\) links \(y_{n+2}\) only to \(y_n\) (same parity). Once \(y_1 = 0\), this forces \(y_3 = 0\), then \(y_5 = 0\), and so on — the zero propagates through all odd-indexed terms. Even derivatives are seeded by \(y_0 = 1\) and so survive.
Topic 2 Active Recall
Mechanism
In Example 1, why does differentiating \((1+x^2)y''\) using Leibnitz produce exactly three non-zero terms?
Because \(u = 1+x^2\) is a polynomial of degree 2. Its derivatives are \(u_0 = 1+x^2\), \(u_1 = 2x\), \(u_2 = 2\), and \(u_k = 0\) for \(k \geq 3\). The Leibnitz sum \(\sum_{k=0}^{n}\binom{n}{k}u_{n-k}v_k\) only contributes when \(u_{n-k} \neq 0\), i.e. when \(n-k \leq 2\). So there are at most three contributing terms.
Computation
Using the recurrence \(y_{n+2} = (5-n^2-n)y_n\) with \(y_0 = 1\), \(y_1 = 0\), compute \(y_6\).
\(n=0\): \(y_2 = (5-0-0)(1) = 5\)

\(n=2\): \(y_4 = (5-4-2)(5) = (-1)(5) = -5\)

\(n=4\): \(y_6 = (5-16-4)(-5) = (-15)(-5) = 75\)
