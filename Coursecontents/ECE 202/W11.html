Week 11Cayley-Hamilton Theorem & Special Matrices

The Cayley-Hamilton theorem says every matrix satisfies its own characteristic equation. It's mainly used to find matrix inverses and powers without direct computation. Special matrices — Hermitian, skew-Hermitian, and unitary — extend the ideas of symmetric, skew-symmetric, and orthogonal matrices to the complex number domain.

Topic 11.1
Cayley-Hamilton Theorem — A Matrix Satisfies Its Own Characteristic Equation

The characteristic equation of an n×n matrix A is the polynomial p(λ) = det(A − λI) = 0. Cayley-Hamilton says: if you replace λ with the matrix A itself in that polynomial, you get the zero matrix. That is, p(A) = 0.

The most useful application is finding A⁻¹. From p(A) = 0 you can isolate A⁻¹ algebraically without computing any determinants or minors directly. The worked examples in the notes use this to find inverses of 2×2 and 3×3 matrices.

Past Q2019/2020 Q3c — Find p(λ) for B = [[3,2],[3,4]] and illustrate Cayley-Hamilton
01
Find the characteristic polynomial p(λ)
B = [ 3 2 ] [ 3 4 ] B - λI = [ 3-λ 2 ] [ 3 4-λ ] det(B - λI) = (3-λ)(4-λ) - (2)(3) = 12 - 3λ - 4λ + λ² - 6 = λ² - 7λ + 6 p(λ) = λ² - 7λ + 6
02
State Cayley-Hamilton: replace λ with B
By Cayley-Hamilton: p(B) = B² - 7B + 6I = 0 We need to compute B²:
03
Compute B²
B² = B × B = [ 3 2 ] × [ 3 2 ] [ 3 4 ] [ 3 4 ] Entry (1,1): 3(3) + 2(3) = 9 + 6 = 15 Entry (1,2): 3(2) + 2(4) = 6 + 8 = 14 Entry (2,1): 3(3) + 4(3) = 9 + 12 = 21 Entry (2,2): 3(2) + 4(4) = 6 + 16 = 22 B² = [ 15 14 ] [ 21 22 ]
04
Verify p(B) = B² − 7B + 6I = 0
7B = [ 21 14 ] 6I = [ 6 0 ] [ 21 28 ] [ 0 6 ] B² - 7B + 6I = [ 15 14 ] - [ 21 14 ] + [ 6 0 ] [ 21 22 ] [ 21 28 ] [ 0 6 ] = [ 15-21+6 14-14+0 ] = [ 0 0 ] = 0 ✓ [ 21-21+0 22-28+6 ] [ 0 0 ]
p(B) = 0 — Cayley-Hamilton verified for B

Topic 11.2
Hermitian, Skew-Hermitian, and Unitary Matrices

These are the complex-number equivalents of symmetric, skew-symmetric, and orthogonal matrices. The key operation is the conjugate transpose A* (also written Aᴴ): take the transpose, then replace every complex number a+bi with its conjugate a−bi.

A Hermitian matrix satisfies A* = A — it equals its own conjugate transpose. Its eigenvalues are always real numbers. A skew-Hermitian matrix satisfies A* = −A. A unitary matrix satisfies A*A = I — its conjugate transpose is its inverse.

Complex Matrix Types
Conjugate A*
Transpose of A, then conjugate every entry: replace (a+bi) with (a−bi).
Hermitian
A* = A. Diagonal entries must be real. Eigenvalues are always real.
Skew-Hermitian
A* = −A. Diagonal entries must be purely imaginary (or zero).
Unitary
A*A = I. The conjugate transpose is the inverse: A* = A⁻¹. |det(A)| = 1.
ExampleVerify A = [[3, 1−i],[1+i, −2]] is Hermitian
01
Compute Aᵀ (transpose)
A = [ 3 1-i ] [ 1+i -2 ] Aᵀ = [ 3 1+i ] ← rows become columns [ 1-i -2 ]
02
Conjugate every entry of Aᵀ to get A*
Conjugate: replace a+bi with a-bi (Aᵀ)* = [ 3 1-i ] ← 3 is real, stays 3 [ 1+i -2 ] ← -2 is real, stays -2 ← 1+i conjugates to 1-i ✓ ← 1-i conjugates to 1+i ✓ A* = [ 3 1-i ] = A ✓ [ 1+i -2 ]
A* = A → A is Hermitian ✓
ExampleVerify A = [[1/√2, 1/√2],[i/√2, −i/√2]] is Unitary (A*A = I)
01
Compute A* (conjugate transpose)
A = [ 1/√2 1/√2 ] [ i/√2 -i/√2 ] Aᵀ = [ 1/√2 i/√2 ] [ 1/√2 -i/√2 ] A* = [ 1/√2 -i/√2 ] ← conjugate i/√2 → -i/√2 [ 1/√2 i/√2 ] ← conjugate -i/√2 → i/√2
02
Compute A*A
A*A = [ 1/√2 -i/√2 ] × [ 1/√2 1/√2 ] [ 1/√2 i/√2 ] [ i/√2 -i/√2 ] Entry (1,1): (1/√2)(1/√2) + (-i/√2)(i/√2) = 1/2 + (-i²/2) = 1/2 + 1/2 = 1 [since i² = -1] Entry (1,2): (1/√2)(1/√2) + (-i/√2)(-i/√2) = 1/2 + (i²/2) = 1/2 - 1/2 = 0 Entry (2,1): (1/√2)(1/√2) + (i/√2)(i/√2) = 1/2 + i²/2 = 1/2 - 1/2 = 0 Entry (2,2): (1/√2)(1/√2) + (i/√2)(-i/√2) = 1/2 + (-i²/2) = 1/2 + 1/2 = 1 A*A = [ 1 0 ] = I ✓ [ 0 1 ]
A*A = I → A is Unitary ✓
The pattern

Symmetric → Hermitian: same idea, extended to complex numbers. Orthogonal → Unitary: same idea. Skew-symmetric → Skew-Hermitian. The "star" operation (conjugate transpose) replaces the "T" operation (plain transpose) as you move from real to complex matrices.

Common Mistake

Taking the conjugate without transposing, or transposing without taking the conjugate. A* requires both steps: first transpose, then conjugate every entry. Doing only one step gives Aᵀ (plain transpose) not A* (conjugate transpose), and the verification will fail.
