Week 2Gaussian Elimination

Gaussian elimination has two phases. Forward pass: use row operations to get 1s on the diagonal and 0s below it (upper triangular form). Back substitution: start from the bottom row where there's only one unknown, find it, then substitute upward until all unknowns are found.

Key Terms
Forward passBack substitutionUpper triangular formPivot = 1 on diagonalZeros below diagonal
Likely Exam Questions
Past Q Solve: 2x₁+3x₂−2x₃−x₄=−2, 2x₁+5x₂−3x₃+x₄=7, −2x₁+x₂+3x₃−2x₄=1, −5x₁+2x₂−x₃+3x₄=8. (Core lecture example)
Solve: 4x₁−2x₂+6x₃−2x₄=11, −3x₁+2x₂+2x₃−4x₄=−9.9, x₁+5x₂−2x₃−2x₄=−3.3, −2x₁+x₂−3x₃+x₄=−5.5.
Topic 2.1
Forward Pass — Full 4×4 Example

Goal: get 1s on the diagonal, 0s below. Work column by column, left to right. For each column: divide the pivot row to make the diagonal entry 1, then subtract multiples of that row from the rows below to make zeros.

Full ExampleForward Pass — Step by step (same system from lecture notes)
01
Form the augmented matrix
System: 2x₁ + 3x₂ - 2x₃ - x₄ = -2 2x₁ + 5x₂ - 3x₃ + x₄ = 7 -2x₁ + x₂ + 3x₃ - 2x₄ = 1 -5x₁ + 2x₂ - x₃ + 3x₄ = 8 [A|C]: R₁ [ 2 3 -2 -1 | -2 ] R₂ [ 2 5 -3 1 | 7 ] R₃ [ -2 1 3 -2 | 1 ] R₄ [ -5 2 -1 3 | 8 ]
02
Make pivot at position (1,1) equal to 1
Divide Row 1 by 2: R₁' = R₁ ÷ 2
R₁'[ 1 3/2 -1 -1/2 | -1 ] ← divided by 2 R₂ [ 2 5 -3 1 | 7 ] R₃ [ -2 1 3 -2 | 1 ] R₄ [ -5 2 -1 3 | 8 ]
03
Clear column 1 — make entries below (1,1) equal zero
R₂' = R₂ − 2·R₁'   R₃' = R₃ + 2·R₁'   R₄' = R₄ + 5·R₁'
R₂' check: [2-2(1), 5-2(3/2), -3-2(-1), 1-2(-1/2) | 7-2(-1)] = [0, 2, -1, 2 | 9 ] R₃' check: [-2+2(1), 1+2(3/2), 3+2(-1), -2+2(-1/2) | 1+2(-1)] = [0, 4, 1, -3 | -1 ] R₄' check: [-5+5(1), 2+5(3/2), -1+5(-1), 3+5(-1/2) | 8+5(-1)] = [0, 19/2, -6, 1/2 | 3 ] After step 3: R₁'[ 1 3/2 -1 -1/2 | -1 ] R₂'[ 0 2 -1 2 | 9 ] R₃'[ 0 4 1 -3 | -1 ] R₄'[ 0 19/2 -6 1/2 | 3 ]
Column 1 done: has 1 at top, zeros below ✓
04
Make pivot at position (2,2) equal to 1
Divide Row 2 by 2: R₂'' = R₂' ÷ 2
R₁' [ 1 3/2 -1 -1/2 | -1 ] R₂''[ 0 1 -1/2 1 | 9/2 ] ← divided by 2 R₃' [ 0 4 1 -3 | -1 ] R₄' [ 0 19/2 -6 1/2 | 3 ]
05
Clear column 2 below the pivot
R₃'' = R₃' − 4·R₂''   R₄'' = R₄' − (19/2)·R₂''
R₃'' = R₃' - 4·R₂'': [0-0, 4-4(1), 1-4(-1/2), -3-4(1) | -1-4(9/2)] = [0, 0, 3, -7 | -19 ] R₄'' = R₄' - (19/2)·R₂'': [0, 19/2-(19/2)(1), -6-(19/2)(-1/2), 1/2-(19/2)(1) | ...] = [0, 0, -6+19/4, 1/2-19/2 | ...] ≈ [0, 0, -5/4, -9 | -33/2 ] After step 5: R₁' [ 1 3/2 -1 -1/2 | -1 ] R₂''[ 0 1 -1/2 1 | 9/2 ] R₃''[ 0 0 3 -7 | -19 ] R₄''[ 0 0 -5/4 -9 | -33/2]
Column 2 done ✓
06
Make pivot at (3,3) = 1, then clear below
R₃''' = R₃'' ÷ 3 then R₄''' = R₄'' + (5/4)·R₃'''
R₃''' = R₃'' ÷ 3: [ 0 0 1 -7/3 | -19/3 ] R₄''' = R₄'' + (5/4)·R₃''': entry (4,3): -5/4 + (5/4)(1) = 0 ← cleared entry (4,4): -9 + (5/4)(-7/3) = -9 - 35/12 = -143/12 RHS: -33/2 + (5/4)(-19/3) = -33/2 - 95/12 = -594/12 → simplified later After step 6: R₁' [ 1 3/2 -1 -1/2 | -1 ] R₂''[ 0 1 -1/2 1 | 9/2 ] R₃'''[ 0 0 1 -7/3 |-19/3 ] R₄'''[ 0 0 0 -143/12| ... ]
07
Make pivot at (4,4) = 1 — forward pass complete
Divide R₄''' by −143/12 to get 1 at position (4,4).
Final upper triangular form: [ 1 3/2 -1 -1/2 | -1 ] [ 0 1 -1/2 1 | 9/2 ] [ 0 0 1 -7/3 |-19/3 ] [ 0 0 0 1 | 4 ] ← x₄ = 4 directly
1s on the diagonal, 0s below. Forward pass done. Now back substitute.
ExampleBack Substitution — reading answers bottom to top
01
Row 4 has one unknown — read directly
Row 4: x₄ = 4
02
Substitute x₄ = 4 into Row 3
Row 3: x₃ - (7/3)·x₄ = -19/3 x₃ - (7/3)(4) = -19/3 x₃ - 28/3 = -19/3 x₃ = -19/3 + 28/3 x₃ = 9/3 = 3
03
Substitute x₃ = 3 and x₄ = 4 into Row 2
Row 2: x₂ - (1/2)·x₃ + x₄ = 9/2 x₂ - (1/2)(3) + 4 = 9/2 x₂ - 3/2 + 4 = 9/2 x₂ + 5/2 = 9/2 x₂ = 4/2 = 2
04
Substitute x₂=2, x₃=3, x₄=4 into Row 1
Row 1: x₁ + (3/2)·x₂ - x₃ - (1/2)·x₄ = -1 x₁ + (3/2)(2) - 3 - (1/2)(4) = -1 x₁ + 3 - 3 - 2 = -1 x₁ - 2 = -1 x₁ = 1
x₁ = 1, x₂ = 2, x₃ = 3, x₄ = 4
Common Mistake

Trying to start back substitution from Row 1. Row 1 still has 4 unknowns — you can't solve it first. Always start from the bottom row (Row 4), which has exactly one unknown. Work upward.

Why This Matters

This 4×4 system is the exact template used in the lecture notes and assignments. Understand every row operation here and you can handle any Gaussian elimination question.
