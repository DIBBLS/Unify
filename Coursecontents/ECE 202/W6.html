Week 6Nullity, Basis & Dimension

Nullity measures how many free variables a homogeneous system has. Rank + Nullity = number of columns — this is the rank-nullity theorem. Basis and dimension describe the structure of vector spaces: a basis is the minimal set of independent vectors that generates the whole space, and dimension is how many you need.

Key Terms
Nullity = cols − rankRank + Nullity = n columnsBasis vectorsDimensionSpanLinear independence
Likely Exam Questions
Find rank and nullity of A = [[1,3,4,3],[3,9,12,9],[−1,3,4,1]].
State the standard basis of R³ and its dimension.
What is the dimension of the solution space of AX = 0 for a matrix with rank 2 and 5 columns?
Topic 6.1
Nullity and the Rank-Nullity Theorem

After row reduction, zero rows = free variables. Nullity counts exactly those free variables. The rank-nullity theorem: rank + nullity = number of columns (not rows — columns).

Rank-Nullity Theorem
Rank(A) + Nullity(A) = n where n = number of COLUMNS Nullity(A) = n - Rank(A)
Critical: n is the column count. Using row count instead is the most common error on this topic.
ExampleRank and Nullity — 3×4 matrix
01
Matrix has 3 rows but 4 columns — n = 4
A = [ 1 3 4 3 ] ← 3 rows [ 3 9 12 9 ] ← 4 columns ← this is n [-1 3 4 1 ] n = 4 (we use this in rank-nullity)
02
Row reduce to find rank
R₂' = R₂ - 3·R₁: [3-3, 9-9, 12-12, 9-9] = [0, 0, 0, 0] → entire zero row R₃' = R₃ + R₁: [-1+1, 3+3, 4+4, 1+3] = [0, 6, 8, 4] After reduction: [ 1 3 4 3 ] [ 0 0 0 0 ] ← zero row [ 0 6 8 4 ] Swap R₂ and R₃: [ 1 3 4 3 ] [ 0 6 8 4 ] [ 0 0 0 0 ] ← zero row Non-zero rows = 2 → Rank = 2
03
Apply rank-nullity theorem
Rank + Nullity = n 2 + Nullity = 4 Nullity = 2 This means: AX = 0 has 2 free variables. The homogeneous solution space has dimension 2.
Rank = 2, Nullity = 2
Common Mistake

Using rows instead of columns: students write nullity = 3 − 2 = 1. Wrong. The theorem uses columns: nullity = 4 − 2 = 2. The matrix has 3 rows, 4 columns. Always count columns for n.

Topic 6.2
Basis and Dimension

A basis is any set of vectors that is (1) linearly independent — none can be built from the others — and (2) spans the space — every vector can be built from them. Dimension = number of vectors in any basis (always the same regardless of which basis you pick).

ExampleStandard basis of R², R³ — decomposing any vector
01
Standard basis of R² — dimension 2
e₁ = (1, 0) e₂ = (0, 1) Any vector in R² = a·e₁ + b·e₂ Example: (5, -3) = 5·(1,0) + (-3)·(0,1) = (5,0) + (0,-3) = (5, -3) ✓
02
Standard basis of R³ — dimension 3
e₁ = (1,0,0) e₂ = (0,1,0) e₃ = (0,0,1) Any vector in R³ = a·e₁ + b·e₂ + c·e₃ Example: (4, -2, 7) = 4·(1,0,0) + (-2)·(0,1,0) + 7·(0,0,1) = (4,0,0) + (0,-2,0) + (0,0,7) = (4, -2, 7) ✓
03
Why this is a valid basis — checking both conditions
Condition 1 (Independent): Can e₁ be built from e₂ and e₃? a·(0,1,0) + b·(0,0,1) = (0, a, b) For this to equal (1,0,0): need first entry = 1, impossible. → e₁, e₂, e₃ are independent ✓ Condition 2 (Spans R³): any (x,y,z) = x·e₁ + y·e₂ + z·e₃ ✓
dim(R²) = 2, dim(R³) = 3, dim(Rⁿ) = n
Standard Basis Vectors in R³
Common Mistake

Thinking there's only one basis for a vector space. Any 3 linearly independent vectors in R³ form a valid basis — not just e₁, e₂, e₃. What is fixed is the dimension (3). Examiners may ask you to find "a basis", not "the basis".

Why This Matters

Connects directly to Week 10: eigenvectors form a basis for eigenspaces, and the dimension of each eigenspace determines whether a matrix is diagonalisable.
