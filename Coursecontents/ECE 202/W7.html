Week 7Types of Matrices

Before you can work with matrices fluently, you need to recognise every type on sight. Each type has special properties that shortcuts later work — a diagonal matrix's determinant is just the product of its diagonal entries, a symmetric matrix has a transpose equal to itself, and so on. This week is about building that visual vocabulary.

Topic 7.1
The Matrix Zoo — Every Type You Need to Know

A matrix is simply a rectangular arrangement of numbers in rows and columns. The position of an element is described as (row, column) — so element a₂₃ is in row 2, column 3. The size is always stated as rows × columns.

Different types of matrices appear constantly in exam questions. Knowing them on sight saves time and prevents errors — you should be able to look at any matrix and immediately say what type it is.

Matrix Types — Definitions and Recognition
Row matrix
Has only one row. e.g. [2, 5, 3, 7] — size 1×4.
Column matrix
Has only one column. e.g. [[1],[9],[4],[8]] — size 4×1.
Square matrix
Same number of rows and columns. A 3×3 or 4×4 matrix is square. Determinants are only defined for square matrices.
Diagonal matrix
Square matrix where all off-diagonal entries are zero. Only the main diagonal (top-left to bottom-right) has non-zero entries.
Identity matrix I
Diagonal matrix with all 1s on the diagonal. Any matrix multiplied by I gives itself: AI = IA = A.
Zero/Null matrix
Every entry is zero. Adding a zero matrix to any matrix changes nothing.
Symmetric
Square matrix where Aᵀ = A. Entry aᵢⱼ = aⱼᵢ for all i, j. The matrix is a mirror across the main diagonal.
Skew-symmetric
Square matrix where Aᵀ = −A. Entry aᵢⱼ = −aⱼᵢ. All diagonal entries must be zero.
Upper triangular
All entries below the main diagonal are zero. The form you produce during the Gaussian forward pass.
Lower triangular
All entries above the main diagonal are zero. The L matrix in LU decomposition.
Singular
Square matrix whose determinant is zero. A singular matrix has no inverse.
Orthogonal
Square matrix where AᵀA = I. Its transpose IS its inverse: Aᵀ = A⁻¹. Determinant = ±1.
Visual Guide — Common Matrix Types
Past Q2019/2020 Q4d — Find x, y, z from matrix equation F − 2G = result
01
Write out F, G, and compute 2G
F = [ 1 -2 ] G = [ 0 1 ] [ 1 3 ] [ 4 3 ] 2G = 2 × [ 0 1 ] = [ 0 2 ] [ 4 3 ] [ 8 6 ]
02
Compute F − 2G
F - 2G = [ 1-0 -2-2 ] = [ 1 -4 ] [ 1-8 3-6 ] [ -7 -3 ]
03
Set equal to given result and match entries
[ 1 -4 ] = [ 1 2x ] [ -7 -3 ] [ y/2 -z ] Entry (1,2): -4 = 2x → x = -2 Entry (2,1): -7 = y/2 → y = -14 Entry (2,2): -3 = -z → z = 3
x = −2, y = −14, z = 3
Past Q2019/2020 Q4e — Evaluate HI and IH, comment on results
01
H is a row matrix (1×2), I is a column matrix (2×1)
H = [ 1 -1 ] (1×2 matrix) I = [ 1 ] (2×1 matrix) [ 2 ]
02
Compute HI — (1×2) × (2×1) = (1×1) result
HI = [ 1 -1 ] × [ 1 ] = [ 1(1) + (-1)(2) ] [ 2 ] = [ 1 - 2 ] = [-1] ← a 1×1 matrix (scalar)
03
Compute IH — (2×1) × (1×2) = (2×2) result
IH = [ 1 ] × [ 1 -1 ] [ 2 ] = [ 1(1) 1(-1) ] = [ 1 -1 ] [ 2(1) 2(-1) ] [ 2 -2 ] ← a 2×2 matrix
04
Comment on results
HI gives a 1×1 scalar result. IH gives a 2×2 matrix result. They are completely different in size — this is why matrix multiplication is NOT commutative. HI ≠ IH in general.
HI = [−1] (scalar), IH = [[1,−1],[2,−2]] (2×2 matrix)
Common Mistake

Assuming matrix multiplication is commutative — that AB = BA. It is not. The order matters both for the result and for whether the multiplication is even possible. You can only multiply A × B if A has as many columns as B has rows.
