Week 9Inverse Matrix & Solving AX = B

The inverse of a matrix A, written A⁻¹, satisfies AA⁻¹ = A⁻¹A = I. Finding it unlocks a clean way to solve AX = B: multiply both sides by A⁻¹ to get X = A⁻¹B. Two methods appear in the notes: the cofactor/adjugate formula and row reduction. Both are examinable.

Key Terms
Inverse A⁻¹Adjugate adj(A)A⁻¹ = adj(A)/det(A)Cofactor matrixRow reduction methodX = A⁻¹B

Topic 9.1
Finding A⁻¹ by Row Reduction

Augment A with the identity matrix I to form [A | I]. Then apply row operations until the left side becomes I. Whatever appears on the right side at that point is A⁻¹. The idea: every operation you do to A, you also do to I, and by the time A is reduced to I, those operations have built up A⁻¹ on the right.

Row Reduction Method for Inverse
[A | I] → row operations → [I | A⁻¹] Then use A⁻¹ to solve AX = B: X = A⁻¹ · B
Only works if det(A) ≠ 0. If A reduces to something other than I on the left, it is singular and has no inverse.
Past Q2019/2020 Q4f — Solve 2x+5y=6, 3x+4y=8 using inverse matrix method

A = [ 2 5 ] X = [ x ] B = [ 6 ] [ 3 4 ] [ y ] [ 8 ] AX = B becomes [ 2 5 ][ x ] = [ 6 ] [ 3 4 ][ y ] [ 8 ]

[ 2 5 | 1 0 ] [ 3 4 | 0 1 ]

Clear column 1: R₂' = R₂ − 3·R₁'
R₂': [3-3, 4-3(5/2), 0-3(1/2), 1-0] = [0, 4-15/2, -3/2, 1] = [0, -7/2, -3/2, 1] [ 1 5/2 | 1/2 0 ] [ 0 -7/2 | -3/2 1 ]
05
Make pivot (2,2) = 1: R₂'' = R₂' × (−2/7)
R₂'' = R₂' × (-2/7): [0, (-7/2)(-2/7), (-3/2)(-2/7), (1)(-2/7)] = [0, 1, 3/7, -2/7] [ 1 5/2 | 1/2 0 ] [ 0 1 | 3/7 -2/7]
06
Clear column 2 above: R₁'' = R₁' − (5/2)·R₂''
R₁'': [1-0, 5/2-(5/2)(1), 1/2-(5/2)(3/7), 0-(5/2)(-2/7)] = [1, 0, 1/2-15/14, 5/7] = [1, 0, 7/14-15/14, 5/7] = [1, 0, -8/14, 5/7] = [1, 0, -4/7, 5/7] [ 1 0 | -4/7 5/7 ] [ 0 1 | 3/7 -2/7 ] A⁻¹ = [ -4/7 5/7 ] [ 3/7 -2/7 ]

x = 16/7, y = 2/7
Topic 9.2
The Adjugate Formula: A⁻¹ = adj(A) / det(A)

The adjugate (also called adjoint) of a matrix is the transpose of its cofactor matrix. Each entry in the cofactor matrix is the cofactor Cᵢⱼ = (−1)ⁱ⁺ʲ × Mᵢⱼ where Mᵢⱼ is the minor (determinant of the submatrix with row i and column j removed).

Once you have the cofactor matrix, you transpose it to get adj(A), then divide by det(A) to get A⁻¹. This method is used in the notes to find C⁻¹ via Cayley-Hamilton (Week 11), but it's also a standalone method.

Adjugate Method
A⁻¹ = adj(A) / det(A) where adj(A) = transpose of the cofactor matrix C Cᵢⱼ = (−1)ⁱ⁺ʲ · Mᵢⱼ
For 2×2: adj([[a,b],[c,d]]) = [[d,−b],[−c,a]]  |  det = ad−bc  |  A⁻¹ = (1/(ad−bc))·[[d,−b],[−c,a]]
ExampleFind inverse of A = [[1,2],[2,3]] using adjugate formula
01
Compute det(A)
A = [ 1 2 ] [ 2 3 ] det(A) = (1)(3) - (2)(2) = 3 - 4 = -1
02
Write adj(A) using 2×2 formula: swap diagonal, negate off-diagonal
adj(A) = [ 3 -2 ] ← swap a and d; negate b and c [ -2 1 ]
03
Compute A⁻¹ = adj(A) / det(A)
A⁻¹ = (1/-1) × [ 3 -2 ] = [ -3 2 ] [ -2 1 ] [ 2 -1 ]
04
Verify: A × A⁻¹ should equal I
[ 1 2 ] × [ -3 2 ] = [ 1(-3)+2(2) 1(2)+2(-1) ] [ 2 3 ] [ 2 -1 ] [ 2(-3)+3(2) 2(2)+3(-1) ] = [ -3+4 2-2 ] = [ 1 0 ] = I ✓ [ -6+6 4-3 ] [ 0 1 ]
A⁻¹ = [[−3,2],[2,−1]] ✓ verified
Common Mistake

In the 2×2 adjugate formula, students swap the diagonal entries but then also swap instead of negate the off-diagonal entries. The rule is: swap a₁₁ and a₂₂, then put a negative sign on a₁₂ and a₂₁. Do not swap them — negate them.
