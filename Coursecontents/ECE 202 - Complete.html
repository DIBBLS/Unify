Week 1Simultaneous Linear Equations

A system of simultaneous equations means several equations that must all be satisfied at the same time. The key skill this week: writing any system as the matrix equation AX = C, and building the augmented matrix [A|C] you'll need for every elimination method.

Key Terms
Coefficient matrix AAugmented matrix [A|C]Unique solutionNo solutionInfinite solutionsPermissible row operations
Likely Exam Questions
Past Q Form A and A_b for: i₁+3i₂−2i₃=6, 4i₁+5i₂+2i₃=3, i₁+3i₂+4i₃=7. Find ranks and nature of solution. (2019/2020 Q1c, 12 marks)
Past Q State conditions for (i) no solution (ii) infinite solutions (iii) unique solution. (2019/2020 Q1b, 5 marks)
Topic 1.1
Writing a System as AX = C

Pull the coefficients into matrix A, the unknowns into column vector X, and the right-hand side into column vector C. Then append C to A to form the augmented matrix — this is the only thing you write when starting any elimination method.

Past Q2019/2020 Q1c — Build the augmented matrix
01
The system
i₁ + 3i₂ - 2i₃ = 6 ... (equation 1) 4i₁ + 5i₂ + 2i₃ = 3 ... (equation 2) i₁ + 3i₂ + 4i₃ = 7 ... (equation 3)
02
Extract coefficient matrix A — coefficients only, no constants
i₁ i₂ i₃ A = [ 1 3 -2 ] ← eq 1 [ 4 5 2 ] ← eq 2 [ 1 3 4 ] ← eq 3
03
Build augmented matrix [A | C] — append the RHS constants
i₁ i₂ i₃ | RHS [A | C] = [ 1 3 -2 | 6 ] [ 4 5 2 | 3 ] [ 1 3 4 | 7 ]
The vertical bar is just notation. Everything to its left came from A; everything to its right came from C.
Common Mistake

Starting row operations on just A without the constants column. Every operation you do must be applied to the full row including the augmented column — otherwise your final answers will be wrong.

Topic 1.2
Three Types of Solutions

Before solving, you can already tell what kind of solution you'll get just by comparing the ranks of A and [A|C].

Solution Conditions — based on Rank
Unique solution
rank(A) = rank([A|C]) = n (n = number of unknowns). Lines cross at one point.
No solution
rank([A|C]) > rank(A). System is inconsistent — equations contradict each other. Parallel lines.
Infinite solutions
rank(A) = rank([A|C]) < n. Equations are not fully independent. Same line (one is a multiple of another).
Past Q2019/2020 Q1c — Determine nature of solution using rank
01
Row reduce A to find rank(A)
A = [ 1 3 -2 ] [ 4 5 2 ] [ 1 3 4 ] R₂ → R₂ - 4·R₁: [4-4, 5-12, 2+8] = [0, -7, 10] R₃ → R₃ - R₁: [1-1, 3-3, 4+2] = [0, 0, 6] A becomes: [ 1 3 -2 ] [ 0 -7 10 ] [ 0 0 6 ] ← 3 non-zero rows → rank(A) = 3
02
Apply same operations to [A|C] to find rank([A|C])
[A|C] = [ 1 3 -2 | 6 ] [ 4 5 2 | 3 ] [ 1 3 4 | 7 ] R₂ → R₂ - 4·R₁: → [0, -7, 10, | -21] R₃ → R₃ - R₁: → [0, 0, 6, | 1] [A|C] becomes: [ 1 3 -2 | 6 ] [ 0 -7 10 | -21] [ 0 0 6 | 1 ] → rank([A|C]) = 3
03
Compare and conclude
rank(A) = 3 rank([A|C]) = 3 n = 3 (unknowns: i₁, i₂, i₃) rank(A) = rank([A|C]) = n = 3
∴ UNIQUE SOLUTION — the system has exactly one answer
Why This Matters

2019/2020 Q1c is 12 marks. Correctly forming [A|C] and finding both ranks earns partial credit even if you don't solve the full system.

Topic 1.3
Three Permissible Row Operations

These are the only operations you're allowed to do to a matrix. They don't change the solution — they just reorganise how the equations are written. Every Gaussian and Gauss-Jordan step is one of these three.

Three Permissible Operations
Rᵢ ↔ Rⱼ
Swap rows i and j. The order of equations doesn't affect the solution.
Rᵢ → k · Rᵢ
Multiply every entry in row i by a non-zero constant k. k must be non-zero — multiplying by 0 destroys the equation.
Rᵢ → Rᵢ + k · Rⱼ
Add k times row j to every entry in row i. This is how you create zeros in specific columns.
Common Mistake

When doing R₂ → R₂ + k·R₁, applying it to only the first few columns and forgetting the augmented constants column. Every entry in the row — including the constant after the vertical bar — must be updated.

Week 2Gaussian Elimination

Gaussian elimination has two phases. Forward pass: use row operations to get 1s on the diagonal and 0s below it (upper triangular form). Back substitution: start from the bottom row where there's only one unknown, find it, then substitute upward until all unknowns are found.

Forward passBack substitutionUpper triangular formPivot = 1 on diagonalZeros below diagonal

Week 3Gauss-Jordan Elimination

Gauss-Jordan takes Gaussian one step further. After the forward pass you keep going — clearing entries above every pivot too — until the left side is the identity matrix. The solution appears directly on the right. No back substitution.

Key Terms
Reduced row echelon form (RREF)Identity matrix on leftEliminate above AND below pivotNo back substitution
Likely Exam Questions
Past Q Solve the same 4×4 system using Gauss-Jordan. (Assignment in notes)
Solve 2x₁+3x₂=1, −4x₁+x₂=5 using Gauss-Jordan.
Explain the difference between Gaussian and Gauss-Jordan elimination.
Topic 3.1
Gauss-Jordan: Clear Above and Below Every Pivot

Difference from Gaussian: after making a pivot = 1, you clear the entire column — not just below. When all pivots are processed, the left side is I (identity) and the right side is your solution.

R₁' = R₁ ÷ 2

R₂' = R₂ + 4·R₁'
R₂': [-4+4(1), 1+4(3/2), 5+4(1/2)] = [0, 7, 7] [ 1 3/2 | 1/2 ] [ 0 7 | 7 ]

Make pivot (2,2) = 1
R₂'' = R₂' ÷ 7

After making a pivot = 1, only clearing below it (Gaussian style) and forgetting to also eliminate above. Week 4LU Decomposition

LU decomposition splits A into two triangular matrices L (lower) and U (upper) where LU = A. Solving AX = C becomes two simple triangular problems: LE = C (forward substitution), then UX = E (back substitution). The notes work through the 3×3 manufacturing problem giving x₁=1, x₂=2, x₃=4.

Key Terms
L = lower triangular, 1s on diagonalU = upper triangular, 1s on diagonalLU = AStep 1: LE = CStep 2: UX = E
Likely Exam Questions
Past Q Solve x₁+3x₂+2x₃=15, 2x₁+4x₂+3x₃=22, 3x₁+4x₂+7x₃=39 using LU decomposition. (Core example — A=1, B=2, C=4)
Decompose A into L and U matrices, show LU = A, then solve LE = C and UX = E.
Topic 4.1
Finding L and U, then Solving in Two Stages

L has 1s on the diagonal and the elimination multipliers below. U has 1s on the diagonal and the modified row values above. You find their entries by expanding LU = A term by term using the formulas from matrix multiplication.

LU Structure (3×3)
L = [ 1 0 0 ] U = [ 1 u₁₂ u₁₃ ] [ l₂₁ 1 0 ] [ 0 1 u₂₃ ] [ l₃₁ l₃₂ 1 ] [ 0 0 1 ] l₁₁ = l₂₂ = l₃₃ = 1 (always, for both L and U diagonals) l₂₁ = a₂₁ u₁₂ = a₁₂ l₃₁ = a₃₁ u₁₃ = a₁₃
Then the remaining entries are found from: l₂₂·u₂₂ + ... = a₂₂ etc.

Why use LU?

If you have the same matrix A but need to solve it for 10 different right-hand sides, LU means you decompose once and run 10 cheap substitutions. Redoing full Gaussian each time would be 10× the work. This is why engineering software prefers LU.

Common Mistake

Mixing up L and U: L is the lower triangle (values below the diagonal come from the elimination multipliers). U is the upper triangle (values above the diagonal come from the modified row entries after scaling). Both have 1s on the main diagonal itself.

Week 5Homogeneous Equations & Rank of a Matrix

Rank tells you how many independent equations a system actually has. Three methods exist to find it: determinant, linear dependence, and row reduction. The notes ask you to use all three on the same matrix. Homogeneous systems (all RHS = 0) always have x = 0 as a solution — the real question is whether others exist.

Key Terms
Homogeneous: AX = 0Trivial solution x = 0Rank3 methodsNon-zero rows after reduction
Likely Exam Questions
Past Q Find rank of A and A_b for 3×3 current system. Nature of solutions. (2019/2020 Q1c)
Find rank of A = [[2,4,6],[1,3,5],[9,10,11]] using all three methods.
Does AX = 0 always have a solution? Explain.
Topic 5.1
Homogeneous vs Non-Homogeneous

Homogeneous: all RHS constants = 0, written AX = 0. x = 0 always satisfies it (trivial solution). Non-trivial solutions exist only when det(A) = 0. Non-homogeneous: at least one RHS ≠ 0. No guarantee of any solution.

Key Distinction
AX = 0
Always has x = 0. Non-trivial solutions exist only if rank(A) < n (equivalently: det(A) = 0).
AX = b (b≠0)
Solution exists only if rank(A) = rank([A|b]). x = 0 is NOT a solution unless b happens to be 0.
Common Mistake

"The homogeneous system has no solution." Wrong. AX = 0 always has x = 0. What you mean is: "the only solution is the trivial solution x = 0." These are different and examiners penalise the incorrect phrasing.

Topic 5.2
Three Methods for Rank — Applied to the Same Matrix

We'll use A = [[2,4,6],[1,3,5],[9,10,11]] from the class notes and apply all three methods. All three must give the same answer.

ExampleMethod 1 — Determinant Method
01
Try the full 3×3 determinant first
A = [ 2 4 6 ] [ 1 3 5 ] [ 9 10 11 ] det(A) = 2·(3·11 - 5·10) - 4·(1·11 - 5·9) + 6·(1·10 - 3·9) = 2·(33-50) - 4·(11-45) + 6·(10-27) = 2(-17) - 4(-34) + 6(-17) = -34 + 136 - 102 = 0 → rank ≠ 3
02
Since det = 0, try the largest 2×2 submatrix
Take top-left 2×2: [ 2 4 ] [ 1 3 ] det = (2×3) - (4×1) = 6 - 4 = 2 ≠ 0 Non-zero 2×2 found → Rank exists at order 2
Rank = 2

R₂' = R₂ - 2·R₁: [2-2(1), 4-2(3), 6-2(5)] = [0, -2, -4] R₃' = R₃ - 9·R₁: [9-9(1), 10-9(3), 11-9(5)] = [0, -17, -34] [ 1 3 5 ] [ 0 -2 -4 ] [ 0 -17 -34 ]

Week 6Nullity, Basis & Dimension

Nullity measures how many free variables a homogeneous system has. Rank + Nullity = number of columns — this is the rank-nullity theorem. Basis and dimension describe the structure of vector spaces: a basis is the minimal set of independent vectors that generates the whole space, and dimension is how many you need.

Key Terms
Nullity = cols − rankRank + Nullity = n columnsBasis vectorsDimensionSpanLinear independence
Likely Exam Questions

Topic 6.1
Nullity and the Rank-Nullity Theorem

After row reduction, zero rows = free variables. Nullity counts exactly those free variables. The rank-nullity theorem: rank + nullity = number of columns (not rows — columns).

Rank-Nullity Theorem
Rank(A) + Nullity(A) = n where n = number of COLUMNS Nullity(A) = n - Rank(A)
Critical: n is the column count. Using row count instead is the most common error on this topic.

A basis is any set of vectors that is (1) linearly independent — none can be built from the others — and (2) spans the space — every vector can be built from them. Dimension = number of vectors in any basis (always the same regardless of which basis you pick).

Topic 7.1
2×2 and 3×3 Determinants by Cofactor Expansion

For a 2×2 matrix the determinant is the product of the main diagonal minus the product of the off-diagonal. For 3×3, expand along the first row — multiply each entry by its cofactor and add. The cofactor absorbs an alternating sign: C₁ⱼ = (−1)^(1+j) × (the 2×2 minor formed by deleting row 1 and column j).

Determinant Formulas

Topic 7.2
Three Key Properties of Determinants

These properties can save enormous work in exam questions — or let you explain why a determinant is zero before calculating. They also tell you exactly what happens to det when you apply the row operations from earlier weeks.

Core Determinant Properties
Row swap
Swapping any two rows multiplies det by −1. Swap twice → sign unchanged.
Scalar multiple
Multiplying one row by k multiplies det by k. Multiplying the whole n×n matrix by k: det(kA) = kⁿ·det(A).
Row addition
Adding a multiple of one row to another does NOT change det. This is why Gaussian elimination preserves the solution set.
Zero row
If any row (or column) is all zeros, det(A) = 0 immediately.
Identical rows
If two rows are identical or proportional, det(A) = 0.
Product rule
det(AB) = det(A) × det(B). Also: det(Aᵀ) = det(A).

R₂' = R₃ − 9·R₂: [0, −17, −34] = 17·[0, 1, 2] This row is a multiple of [0,1,2]. After full reduction: matrix gains a zero row. det(reduced matrix) = 0. Row addition does not change det, so det(A) = 0 also.

Common Mistake

Writing det(2A) = 2·det(A). For a 3×3 matrix: det(2A) = 2³·det(A) = 8·det(A). The scalar is raised to the power n, not multiplied once. A 3×3 matrix has 3 rows, each picked up the factor of 2.

Week 8Matrix Inverse — Adjoint & Gauss-Jordan

The inverse A⁻¹ satisfies AA⁻¹ = A⁻¹A = I. It only exists when det(A) ≠ 0 (non-singular). Two methods: the adjoint method uses cofactors — A⁻¹ = adj(A)/det(A); the Gauss-Jordan method row-reduces [A|I] until the left side becomes I, after which the right side is A⁻¹. Both methods must give the same answer — use that as a check.

Key Terms
A⁻¹ exists iff det(A) ≠ 0Cofactor Cᵢⱼ = (−1)^(i+j)·Mᵢⱼadj(A) = transpose of cofactor matrixA⁻¹ = adj(A)/det(A)[A|I] → [I|A⁻¹]

Topic 8.1
Adjoint Method — A⁻¹ = adj(A) / det(A)

Steps: (1) compute det(A) — stop if zero; (2) find all 9 cofactors using the sign checkerboard; (3) write the cofactor matrix C; (4) TRANSPOSE C to get adj(A) — this is the step most students miss; (5) divide every entry of adj(A) by det(A).

Adjoint Method — 3×3 Steps
Step 1: Compute det(A). If = 0, stop — inverse does not exist. Step 2: Cᵢⱼ = (−1)^(i+j) × Mᵢⱼ for all 9 positions (i,j) Step 3: Cofactor matrix C = all 9 cofactors in their positions Step 4: adj(A) = Cᵀ ← TRANSPOSE — rows become columns Step 5: A⁻¹ = (1/det(A)) × adj(A)
Critical: adj(A) = Cᵀ, NOT C. The transpose swaps Cᵢⱼ and Cⱼᵢ. Only if C is symmetric does adj(A) = C.

Using the cofactor matrix C directly as adj(A) without transposing. The transpose swaps position (i,j) and (j,i). Only if the matrix is symmetric will C = Cᵀ happen to be true. Always write and perform the transpose step explicitly.

Week 9Eigenvalues

An eigenvalue λ of matrix A is a scalar such that Av = λv for some non-zero vector v. The equation says: A transforms v by simply scaling it — not rotating or shearing it. All eigenvalues are found by solving the characteristic equation det(A − λI) = 0. For 2×2 this is a quadratic; for 3×3 a cubic — but exam matrices are always chosen to factorise neatly.

Topic 9.1
The Characteristic Equation — det(A − λI) = 0

Eigenvalues exist at values of λ where (A − λI) becomes singular — where its rows become linearly dependent and its determinant hits zero. Expand that determinant as a polynomial in λ (the characteristic polynomial), then solve for its roots. Each root is an eigenvalue.

Characteristic Equation

tr(A) = trace = sum of main diagonal. Always verify eigenvalues against both checks before moving to eigenvectors.

A negative eigenvalue means exponential decay; positive means growth; purely imaginary means sustained oscillation. Engineers solve for eigenvalues before designing any feedback system.

Week 10Eigenvectors & Eigenspaces

Topic 10.2

When an eigenvalue appears k times in the characteristic polynomial (algebraic multiplicity k), it may produce between 1 and k independent eigenvectors. The actual count is the geometric multiplicity — the dimension of the eigenspace. Geometric multiplicity ≤ algebraic multiplicity always. When they are equal for every eigenvalue, the matrix is diagonalizable.

Week 11Diagonalization

Diagonalization rewrites A = PDP⁻¹ where D is a diagonal matrix of eigenvalues and P is the matrix whose columns are the corresponding eigenvectors. This factorisation makes repeated multiplication trivial: Aⁿ = PDⁿP⁻¹, and Dⁿ is just each diagonal entry raised to the power n. A matrix is diagonalizable when it has n linearly independent eigenvectors.

P⁻¹A = [ 1/2 1/2 ] · [ 3 1 ] [ -1/2 1/2 ] [ 1 3 ] Row 1: [1/2·3+1/2·1, 1/2·1+1/2·3] = [2, 2] Row 2: [-1/2·3+1/2·1, -1/2·1+1/2·3] = [-1, 1] P⁻¹A = [ 2 2 ] [ -1 1 ] (P⁻¹A)P = [ 2 2 ] · [ 1 -1 ] [ -1 1 ] [ 1 1 ] Row 1: [2+2, -2+2] = [4, 0] Row 2: [-1+1, 1+1] = [0, 2]
P⁻¹AP = [[4,0],[0,2]] = D ✓
Common Mistake

Swapping the order: putting λ₁ in column 1 of D but v₂ in column 1 of P. The pairing must be consistent. If you reorder the eigenvectors, you must reorder the eigenvalues in D to match. A mismatch will give P⁻¹AP ≠ D and the diagonalization fails.

Topic 11.2
Matrix Powers — Aⁿ = PDⁿP⁻¹

Since A = PDP⁻¹, multiplying A by itself repeatedly collapses cleanly: each adjacent P⁻¹·P pair cancels to I, leaving only P, Dⁿ, and P⁻¹. Computing Dⁿ is trivial — each diagonal entry is just raised to the power n. This turns a chain of n matrix multiplications into exactly three.

Matrix Powers via Diagonalization
A = PDP⁻¹ A² = (PDP⁻¹)(PDP⁻¹) = PD(P⁻¹P)DP⁻¹ = PD²P⁻¹ Aⁿ = PDⁿP⁻¹ For 2×2: Dⁿ = [ λ₁ⁿ 0 ] [ 0 λ₂ⁿ ]
The cancellation P⁻¹P = I is what collapses the chain. Aⁿ = PⁿDⁿ(P⁻¹)ⁿ is WRONG — P appears exactly once, not raised to a power.
ExampleCompute A³ for A = [[3,1],[1,3]] using diagonalization
01
Compute D³ — raise diagonal entries to the power 3
D³ = [ 4³ 0 ] = [ 64 0 ] [ 0 2³] [ 0 8 ]
02
Compute P·D³
P·D³ = [ 1 -1 ] · [ 64 0 ] [ 1 1 ] [ 0 8 ] Row 1: [1·64 + (−1)·0, 1·0 + (−1)·8] = [64, -8] Row 2: [1·64 + 1·0, 1·0 + 1·8] = [64, 8] P·D³ = [ 64 -8 ] [ 64 8 ]
03
Compute (P·D³)·P⁻¹
(P·D³)·P⁻¹ = [ 64 -8 ] · [ 1/2 1/2 ] [ 64 8 ] [ -1/2 1/2 ] Row 1: [64/2 + 8/2, 64/2 − 8/2] = [36, 28] Row 2: [64/2 − 8/2, 64/2 + 8/2] = [28, 36]
A³ = [[36, 28],[28, 36]]
04
Verify by direct computation
A² = [ 3 1 ]·[ 3 1 ] = [ 9+1 3+3 ] = [ 10 6 ] [ 1 3 ] [ 1 3 ] [ 3+3 1+9 ] [ 6 10 ] A³ = A²·A = [ 10 6 ]·[ 3 1 ] = [ 30+6 10+18 ] = [ 36 28 ] ✓ [ 6 10 ] [ 1 3 ] [ 18+10 6+30 ] [ 28 36 ] ✓
Why This Is Powerful

Computing A¹⁰ directly needs 9 matrix multiplications. With diagonalization: raise each eigenvalue to the 10th power (trivial), then multiply three matrices. For a 100×100 engineering system, diagonalization is the only practical approach.

Topic 12.1
Cramer's Rule — One Determinant per Unknown

For AX = C with det(A) ≠ 0: to find xᵢ, replace column i of A with the RHS column vector C, compute the determinant of the resulting matrix, and divide by det(A). Each unknown gets its own modified matrix. For 2×2 and 3×3 exam systems this is often the fastest method.

Cramer's Rule
For n×n system AX = C with det(A) ≠ 0: x₁ = det(A₁)/det(A) A₁ = A with column 1 replaced by C x₂ = det(A₂)/det(A) A₂ = A with column 2 replaced by C x₃ = det(A₃)/det(A) A₃ = A with column 3 replaced by C If det(A) = 0: Cramer's rule does NOT apply. → Check rank(A) vs rank([A|C]) to determine solution type (Week 1).
Aᵢ keeps all columns of A except column i — only that one column is swapped with C.
Full Example2×2 system — 2x₁ + x₂ = 5, x₁ + 3x₂ = 10
01
Identify A and C, then compute det(A)
A = [ 2 1 ] C = [ 5 ] [ 1 3 ] [ 10 ] det(A) = (2)(3) − (1)(1) = 6 − 1 = 5 ← non-zero, rule applies
02
Form A₁ — replace column 1 with C
A₁ = [ 5 1 ] det(A₁) = (5)(3) − (1)(10) = 15 − 10 = 5 [ 10 3 ] x₁ = det(A₁)/det(A) = 5/5 = 1
03
Form A₂ — replace column 2 with C
A₂ = [ 2 5 ] det(A₂) = (2)(10) − (5)(1) = 20 − 5 = 15 [ 1 10 ] x₂ = det(A₂)/det(A) = 15/5 = 3
04
Verify in original equations
Eq 1: 2(1) + 1(3) = 2 + 3 = 5 ✓ Eq 2: 1(1) + 3(3) = 1 + 9 = 10 ✓
x₁ = 1, x₂ = 3
Common Mistake

Replacing the wrong column. For x₂, you replace ONLY column 2 of A with C — columns 1 and 3 stay as they are from A. Many students accidentally replace all columns, or replace the column by a single number instead of the full vector C.

Systems of Equations — Weeks 1–4
Matrix form
AX = C → form augmented matrix [A|C] before any row operation.
Solution type
rank(A) = rank([A|C]) = n → unique. rank(A) = rank([A|C]) < n → infinite. rank([A|C]) > rank(A) → no solution.
Gaussian
Forward pass → upper triangular (1s on diagonal, 0s below). Then back substitution bottom to top.
Gauss-Jordan
Clear above AND below every pivot → RREF (identity on left). Read solution directly, no back substitution.
LU decomposition
Factor A = LU. Solve LE = C (forward sub) → solve UX = E (back sub). Both L and U have 1s on diagonal.
Rank, Nullity & Basis — Weeks 5–6
Rank
Number of non-zero rows after row reduction. Three methods: determinant, linear dependence, row reduction.
Rank-Nullity
rank(A) + nullity(A) = n where n = number of COLUMNS (not rows).
Homogeneous AX=0
Always has x=0 (trivial). Non-trivial solutions exist iff rank(A) < n.
Basis / Dimension
Basis = linearly independent set that spans the space. dim(Rⁿ) = n.
Determinants & Inverse — Weeks 7–8
3×3 cofactor det
a₁₁(+M₁₁) + a₁₂(−M₁₂) + a₁₃(+M₁₃). Sign checkerboard: + − + / − + − / + − +.
det(kA)
det(kA) = kⁿ·det(A) for n×n. det(AB) = det(A)·det(B). det(Aᵀ) = det(A).
Adjoint inverse
A⁻¹ = adj(A)/det(A). adj(A) = Cᵀ (TRANSPOSE of cofactor matrix C).
Gauss-Jordan inverse
[A|I] → row reduce → [I|A⁻¹]. Apply every operation to both sides.
Cramer's rule
xᵢ = det(Aᵢ)/det(A). Aᵢ = A with column i replaced by C. Only when det(A) ≠ 0.
Eigenvalues, Eigenvectors & Diagonalization — Weeks 9–11
Eigenvalues
Solve det(A−λI) = 0. Verify: Σλᵢ = tr(A), Πλᵢ = det(A).
Eigenvectors
For each λ: row-reduce (A−λI), set free variable = t, write non-zero vector. Verify Av = λv.
Diagonalization
P = [v₁|v₂|…] (eigenvectors as columns). D = diag(λ₁, λ₂, …). P⁻¹AP = D.
Matrix powers
Aⁿ = PDⁿP⁻¹. Dⁿ = diag(λ₁ⁿ, λ₂ⁿ, …). P appears exactly once on each side.
Diagonalizable?
Yes iff n linearly independent eigenvectors exist — i.e. geometric mult = algebraic mult for every eigenvalue.

Answer definition and condition questions first — they are 5 marks for 2 minutes of writing. On computation questions, always write: (1) the matrix or formula you are using, (2) each row operation explicitly, (3) a verification step. Partial marks are awarded for correct setup even when arithmetic errors appear later. The trace-and-determinant check for eigenvalues and the AA⁻¹ = I check for inverse are two-line verifications that protect marks you already earned.
