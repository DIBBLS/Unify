Unify — Import Codes

One-time tool to write your generated CSV codes into Firestore.
Must be served from localhost — open a terminal in your Unify folder and run:
python -m http.server 8000 then visit http://localhost:8000/import-codes.html

Header row is ignored. Accepts "1 Month", "3 Months", or "6 Months" in the Tier column.
